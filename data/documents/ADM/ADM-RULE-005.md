## 第 1 條 適用範圍

全體員工因公務離開廠區所在地（台中市）的出差。台中市內的外出洽公不算出差，交通費依實報實銷。

## 第 2 條 核准

| 類別                     | 核准層級               | 申請時間           |
| ------------------------ | ---------------------- | ------------------ |
| 國內，3 天以內           | L1 課長／組長          | 出發前 2 個工作天   |
| 國內，超過 3 天          | L2 部門經理            | 出發前 5 個工作天   |
| 國外，7 天以內           | L3 廠長                | 出發前 15 個工作天  |
| 國外，超過 7 天          | L4 總經理              | 出發前 20 個工作天  |

出差申請填寫方式見 ADM-FORM-002。

## 第 3 條 國內出差

### 交通

| 項目               | 規定                                                    |
| ------------------ | ------------------------------------------------------- |
| 高鐵               | 標準車廂                                                |
| 台鐵、客運         | 實報實銷                                                |
| 自行開車           | 每公里 4 元（含油資、過路費），需事先在申請單註明       |
| 計程車             | 限攜帶大量樣品、深夜（22:00 後）或無大眾運輸時          |
| 公務車             | 向總務預約；使用後填寫里程紀錄                          |

### 日支費與住宿

| 項目                     | 金額（新台幣）                         |
| ------------------------ | -------------------------------------- |
| 日支費（膳雜費）          | 800 元／日；當日往返 400 元             |
| 住宿費上限（台北市、新北市） | 3,200 元／晚                        |
| 住宿費上限（其他地區）    | 2,800 元／晚                           |

- 住宿超過上限的部分自付，除非部門經理事先同意（例如展覽期間）。
- 客戶或供應商招待用餐時，該餐日支費扣除 200 元。

## 第 4 條 國外出差

### 交通

- 航程 6 小時以內：經濟艙。
- 航程超過 6 小時：經濟艙；L3 以上主管可搭乘豪華經濟艙。
- 機票由行政管理部統一訂購，不可自行購買後報支（緊急情況除外）。

### 日支費與住宿（新台幣）

| 地區                               | 日支費     | 住宿上限／晚 |
| ---------------------------------- | ---------- | ------------ |
| 中國大陸、香港、東南亞             | 2,500 元   | 4,500 元     |
| 日本、韓國                         | 3,200 元   | 6,000 元     |
| 歐洲、美洲                         | 3,600 元   | 7,500 元     |

- 出發與返國當日以半日計算日支費。
- 簽證費、旅遊平安保險、機場交通實報實銷。

### 預支

國外出差可預支日支費與住宿費合計的 80 %，出發前 5 個工作天申請。

## 第 5 條 報支

1. 返回後 **10 個工作天內**報支，逾期未報支須經部門經理核准說明。
2. 預支款在報支時沖銷，多退少補。
3. 收據抬頭須為公司名稱與統一編號；國外收據附刷卡紀錄。
4. 報支單填寫方式見 ADM-FORM-002。

## 第 6 條 保險與安全

1. 國外出差由公司加保旅遊平安保險（保額 500 萬元）與海外醫療。
2. 出差期間攜帶公司筆電，依資訊安全規範：不使用公共無線網路處理公司資料，必要時使用公司 VPN。
3. 不得攜帶配方資訊、客戶合約等機密資料出國，除非經部門經理核准。
4. 遇到天災、疫情或治安事件，立即聯繫主管與行政管理部。

## 1. 適用範圍

- 產品：HC-200 光學硬塗膜（亮面），基材 BF-P050。
- 產線：CL-01。
- 本規格是 CL-01 配方系統中 HC-200 配方的設定依據。配方系統內的數值與本規格不一致時，以本規格為準，並通報 PE 修正配方。

| 項目         | 規格           |
| ------------ | -------------- |
| 塗層乾膜厚度 | 3.0 ± 0.3 µm   |

## 4. 參數之間的關係（調整時注意）

1. **線速與 UV 光量**：線速提高 10 %，UV 累積光量約下降 10 %。線速調到 22 m/min 時，光量約 365 mJ/cm²，接近下限，必須先確認燈管狀態。
2. **燈管衰減**：高壓汞燈累積 1,000 小時後，光量約比新燈低 12–15 %。燈管更換基準為 1,200 小時（ECN-2026-011）。
3. **烘箱與硬度**：第 3 區低於 85 °C，溶劑殘留會讓 UV 固化後硬度下降，即使 UV 光量合格也可能只有 H。
4. **塗布間隙**：間隙過大（> 70 µm）塗布珠不穩定，容易出現條紋；過小（< 50 µm）易刮傷基材。

## 5. 超出規格時的處置

| 狀況                                     | 處置                                                              | 權限       |
| ---------------------------------------- | ----------------------------------------------------------------- | ---------- |
| 參數偏離目標但在上下限內                 | 現場持續監控，記錄於巡檢表                                        | 製造部     |
| 參數超出上下限，可在 15 分鐘內恢復       | 恢復設定，該段標示待判，通報 PE 值班                              | 製造部 + PE |
| 參數超出上下限，無法恢復                 | 停線，依異常代碼通報                                              | 製造部     |
| UV 光量低於 350 mJ/cm²                   | 視同 D10 硬度不足風險，停線；不得以降速補償                       | 製造部     |
| 需要在上下限內調整目標值                 | PE 值班決定，記錄調整原因與時間                                   | PE         |
| 需要改變上下限或目標值本身               | 依 PE-RULE-001 開立 ECN                                           | PE 經理    |

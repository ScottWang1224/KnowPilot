## 第 1 條 適用範圍

公司所有管理文件（規章、SOP、規格、表單、計畫、教育訓練教材）與品質紀錄。

## 第 2 條 文件編號

格式：**部門代碼-類型-序號**，例：MFG-SOP-003。

| 部門代碼 | 部門       |
| -------- | ---------- |
| MFG      | 製造部     |
| PE       | 製程工程部 |
| QA       | 品質保證部 |
| RD       | 研發部     |
| ADM      | 行政管理部 |

| 類型 | 說明                         |
| ---- | ---------------------------- |
| RULE | 規章、辦法                   |
| SEC  | 資訊保護規範                 |
| SOP  | 標準作業程序                 |
| SPEC | 規格                         |
| TRN  | 教育訓練教材                 |
| RPT  | 報告                         |
| 8D   | 8D 問題解決報告              |
| ECN  | 製程變更通知                 |
| FORM | 表單與填寫說明               |
| PLAN | 計畫                         |

全公司適用的文件，使用負責部門的代碼。

## 第 3 條 制定與改版

| 文件類型                     | 審查           | 核准             |
| ---------------------------- | -------------- | ---------------- |
| 全公司規章                   | 相關部門會簽   | 總經理           |
| 部門規章、SOP、規格、計畫    | 部門內         | 部門經理         |
| 涉及其他部門作業的 SOP       | 相關部門會簽   | 部門經理         |
| 報告、8D                     | —              | 部門經理         |

- 版本以「主版本.次版本」表示（例：2.1）。內容實質變更升主版本或次版本，由文件負責人判斷；錯字修正不改版。
- 每份文件記錄修訂紀錄與生效日期。
- 文件每 2 年至少檢討一次，無變更者記錄「檢討無修改」。

## 第 4 條 發行與權限

1. 文件經核准後，由文件管制人員發行到公司文件系統與內部知識平台。
2. 文件分為兩種開放範圍：
   - **全公司**：所有員工可查閱。
   - **部門限定**：只有負責部門的員工可查閱。
3. 需要查閱其他部門的部門限定文件時，向該部門經理申請；核准後由該部門提供必要的部分。
4. 現場張貼或紙本使用的文件，必須蓋「管制文件」章；未蓋章的影本不得作為作業依據。

## 第 5 條 作廢

1. 文件改版發行時，舊版同時作廢；系統只保留現行版供查閱，舊版由文件管制人員歸檔。
2. 現場紙本由文件負責部門在新版發行當天收回舊版。
3. 作廢的文件歸檔保存 3 年。

## 第 6 條 紀錄保存年限

| 紀錄                                   | 保存年限                 |
| -------------------------------------- | ------------------------ |
| 生產紀錄、批次紀錄、交接簿             | 3 年                     |
| 進料與製程檢驗紀錄                     | 3 年                     |
| 出貨檢驗紀錄                           | 5 年                     |
| 8D 報告、客訴紀錄                      | 10 年                    |
| 製程變更（ECN）                         | 10 年                    |
| 教育訓練紀錄                           | 員工離職後 5 年          |
| 量測儀器校正紀錄                       | 儀器報廢後 3 年          |

紀錄以電子檔為主；紙本紀錄 1 年後掃描歸檔。

## 第 7 條 知識平台

內部知識平台 KnowPilot 只收錄已發行的現行版文件。平台的回答以文件為依據並附來源編號；作業前仍應以原文件確認。

本文件為虛構企業展示資料，內容與數值不得用於真實生產。

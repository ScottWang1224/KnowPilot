## 1. 適用範圍

公司所有採購，包括原物料、設備、備品、耗材、服務與一般用品。員工個人代墊的小額費用依出差或費用報支規定辦理，不在本程序範圍。

## 2. 流程

| 步驟 | 內容                                               | 負責           | 時限                       |
| ---- | -------------------------------------------------- | -------------- | -------------------------- |
| 1    | 填寫請購單（說明見 ADM-FORM-001）                   | 請購部門       | —                          |
| 2    | 請購核准（依第 3 節金額）                           | 請購部門主管   | 2 個工作天                 |
| 3    | 詢價、比價、議價                                   | 採購課         | 一般 5 個工作天；急件 2 天 |
| 4    | 採購核准（依第 3 節金額）                           | 核決主管       | 2 個工作天                 |
| 5    | 下訂單                                             | 採購課         | 核准後 1 個工作天          |
| 6    | 交貨與驗收                                         | 倉庫、請購部門、QA（原物料） | 依第 5 節           |
| 7    | 請款與付款                                         | 採購課、財務   | 月結 60 天                 |

## 3. 核決權限（含稅總金額）

| 金額（新台幣）           | 核決層級              |
| ------------------------ | --------------------- |
| 30,000 元以下            | L1 課長／組長         |
| 30,001～200,000 元        | L2 部門經理           |
| 200,001～1,000,000 元     | L3 廠長               |
| 1,000,001 元以上          | L4 總經理             |

- 同一需求不得拆單規避核決層級；採購課發現拆單時退回請購部門。
- 年度合約採購（例如原物料年度議價）依年度總額核決，單次訂購由採購課長核准。

## 4. 詢比價

| 金額                     | 要求                                         |
| ------------------------ | -------------------------------------------- |
| 30,000 元以下            | 1 家報價即可                                 |
| 30,001～200,000 元        | 至少 2 家報價                                |
| 200,001 元以上            | 至少 3 家報價，並填寫比價表                  |

例外（可只有 1 家報價，需在請購單說明）：

- 原物料：只向合格供應商名單內的供應商採購（供應商評鑑見 ADM-RULE-006）。
- 原廠指定備品、獨家技術服務。

## 5. 驗收

| 類別           | 驗收方式                                          | 時限           |
| -------------- | ------------------------------------------------- | -------------- |
| 原物料         | 倉庫點收數量 → 品質保證部進料檢驗                 | 2 個工作天     |
| 設備           | 請購部門安裝測試，簽驗收單                        | 依合約，通常 30 天內 |
| 一般用品、耗材 | 倉庫點收，請購部門確認                            | 3 個工作天     |

- 驗收不合格：採購課 2 個工作天內通知供應商退換。
- 設備金額 80,000 元以上列為固定資產，驗收後依 ADM-SOP-004 登錄。

## 6. 急件

1. 生產停線或安全相關的急件，請購部門主管可先以電話核准，採購課當天下單，2 個工作天內補齊書面。
2. 急件每月統計，同一部門每月超過 3 件，由行政管理部經理了解原因。

## 7. 利益迴避

採購人員與供應商有親屬關係或財務往來時，應主動申報並迴避該供應商的採購。不得收受供應商 3,000 元以上的餽贈。

本文件為虛構企業展示資料，內容與數值不得用於真實生產。

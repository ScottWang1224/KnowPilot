## 1. 背景

1. HC-400 開發需要在較低 UV 光量下達到 4H 硬度（見 RD-RPT-003），需要固化效率更高的光起始劑。
2. 客戶 A 曾反映 HC-230AG 長期使用後有輕微黃變，希望評估低黃變的方案。

候選材料 RM-P02（供應商 V07，評估中）。

## 2. 評估方法

- 以 FM-HC-021 R4（HC-200）為基礎，RM-P01 4.0 % 分別以 RM-P02 3.0 %、4.0 % 取代。
- 研發塗布機塗布 3.0 µm，UV 光量 250–450 mJ/cm²。
- 樣品 RS-2609-021 至 RS-2609-036。

## 3. 結果

### 3.1 達到 2H 所需的最低 UV 光量

| 光起始劑         | 最低光量         |
| ---------------- | ---------------- |
| RM-P01 4.0 %（現用） | 340 mJ/cm²   |
| RM-P02 3.0 %     | 300 mJ/cm²       |
| RM-P02 4.0 %     | 270 mJ/cm²       |

RM-P02 4.0 % 所需光量約減少 20 %。

### 3.2 其他特性（UV 400 mJ/cm²）

| 項目                           | RM-P01 4.0 % | RM-P02 4.0 % |
| ------------------------------ | ------------ | ------------ |
| 初期黃色指數 b*                | 0.9          | 0.6          |
| 85 °C／85 % RH 500 小時後 b*    | 1.8          | 1.0          |
| 霧度                           | 0.42 %       | 0.43 %       |
| 透光率                         | 91.8 %       | 91.9 %       |
| 塗液 25 °C 放置 7 天黏度變化     | + 3 %        | + 9 %        |
| 氣味（固化後，5 人官能評估）   | 輕微         | 幾乎無       |

## 4. 討論

1. 固化效率與低黃變都優於 RM-P01。
2. **塗液安定性較差**：7 天黏度上升 9 %。HC 塗液目前調配後最長使用 5 天，RM-P02 需要縮短到 3 天以內，對調配排程有影響。
3. V07 尚未通過供應商評鑑；單價較高。
4. 更換量產配方的光起始劑屬一級變更，客戶 A、B 都需要重新認證。

## 5. 結論

| 對象                         | 建議                                                 |
| ---------------------------- | ---------------------------------------------------- |
| HC-200、HC-350、HC-230AG（量產） | **不更換**。效益不足以抵銷重新認證與安定性風險        |
| HC-400（開發中）             | **採用 RM-P02**，納入 FM-HC-041 R3 評估                |
| 客戶 A 黃變需求              | 另案評估，先由 QA 確認客戶實際使用條件                |

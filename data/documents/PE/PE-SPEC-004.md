## 1. 適用範圍

CL-02 生產的 RF-12（輕離型）、RF-25（中離型）、RF-50（重離型）。三個產品使用同一條線、同一套烘箱，差別在凹版輥、塗液固含量與固化溫度。

## 4. 固化條件

### 4.1 固化區

第 1、2 區主要蒸發溶劑（正庚烷），**第 3、4 區是主要固化區**，第 5 區為後固化與降溫過渡。離型力與殘餘接著率主要取決於第 3、4 區的實際溫度與停留時間。

### 4.2 固化不足的判斷

| 指標                                       | 判斷                                     |
| ------------------------------------------ | ---------------------------------------- |
| 第 3 或第 4 區中段溫度低於設定值 > 5 °C     | 固化不足風險，視為 D09 疑似              |
| 第 3、4 區任一加熱器斷線警報               | 停線檢查                                 |
| 線速高於設定值 > 5 m/min                    | 停留時間不足，回到設定值                 |
| 塗液加觸媒後 > 7 小時                      | 反應性下降，換新批塗液                   |
| 擦拭脫落（rub-off）測試有脫落               | 固化不足，停線                           |

固化不足時，未交聯的矽成分會轉移到客戶的膠面，表現為**離型力偏高、殘餘接著率下降**。

### 4.3 溫度監控（2026-03 起）

1. 每區有 3 支熱電偶：入口、中段、出口。**控制與判定一律以中段熱電偶為準**。
2. 2026-02 之前控制器讀的是加熱器出口熱電偶，該處溫度在加熱器部分斷線時仍維持正常，無法反映區內實際溫度。
3. 每區加熱器裝有斷線偵測，任一支斷線即亮燈並發出警報。
4. 中段熱電偶每季校正一次（見 PE-PLAN-001）。

## 5. 塗佈量調整（PE 執行）

| 調整                    | 塗佈量變化（約）         | 備註                           |
| ----------------------- | ------------------------ | ------------------------------ |
| 輥速比 + 0.1            | + 0.008 g/m²             | 優先使用                       |
| 塗液固含量 + 0.2 %      | + 0.007 g/m²             | 需調配組重新調整               |
| 刮刀壓力 + 0.03 MPa      | − 0.004 g/m²             | 壓力過高會加速刮刀磨損         |

塗佈量偏離時，先用輥速比在 ± 0.1 內調整；超出範圍時依 PE-RULE-001 開立 ECN。**不可以用改變烘箱溫度的方式調整離型力**。

## 6. 超出規格時的處置

| 狀況                                     | 處置                                                         |
| ---------------------------------------- | ------------------------------------------------------------ |
| 烘箱溫度超出 ± 5 °C，15 分鐘內恢復       | 該段標示待判，依快速篩檢結果判定                             |
| 烘箱溫度無法恢復                         | 停線，通報設備課；恢復後試產 200 m 快速篩檢合格才可量產       |
| 快速篩檢 B 級／A 級                     | 依 MFG-SOP-010；PE 負責原因調查                               |
| 塗佈量（XRF）超出規格                    | 調整輥速比；連續 2 卷超出時停線檢查凹版輥網穴                |

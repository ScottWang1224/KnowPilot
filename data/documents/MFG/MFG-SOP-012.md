## 1. 目的

新產品從研發部移轉到量產前，需要在 CL-01 或 CL-02 上試產。本文件說明製造部在試產中要做什麼、不能做什麼，讓試產資料可信，也不影響量產品。

## 2. 適用範圍

- 研發部發出試產通知、在量產線上進行的所有試產。
- 試產案一律以試產代號 NP-年份-序號 稱呼。**製造部的排程、標籤與紀錄只寫試產代號**，不寫開發中產品的型號或配方資訊。
- 製程條件由 PE 提供，試產塗液由研發部提供；製造部負責依條件操作與記錄。

## 3. 角色分工

| 角色               | 負責                                                   |
| ------------------ | ------------------------------------------------------ |
| 研發部             | 發出試產通知、提供試產塗液、試產現場技術指導           |
| PE                 | 提供「試產條件表」、決定試產中的參數調整               |
| 製造部 課長        | 安排試產時段與人員、主持試產前會議                     |
| 製造部 班長        | 試產當班指揮、確認標示與隔離                           |
| QA                 | 首件檢驗與試產樣品量測                                 |

## 4. 試產前（至少 3 個工作天前）

1. 課長收到試產通知後，與生管組確認時段，原則上排在**早班**，PE 與研發人員在廠。
2. 召開試產前會議（課長、班長、PE、研發、QA），確認：
   - 試產條件表的版本，與量產產品條件不同的項目。
   - 試產長度：每次試產原則上 ≤ 1,000 m；超過需製造部經理同意。
   - 試產前後要接哪一個量產產品、需要的清潔與換線方式（依 MFG-SOP-005 或 MFG-SOP-006）。
   - 試產塗液的數量、交付時間與剩餘塗液處理方式。
3. 會議紀錄由班長保存，並寫入交接簿。

## 5. 人員資格

- 試產當班的主操作員必須具有該線**三級**技能檢定（見 MFG-TRN-002）。
- 二級操作員可以協助放卷、收卷與取樣，不可操作控制面板。

## 6. 物料與母卷標示

| 項目         | 規定                                                                    |
| ------------ | ----------------------------------------------------------------------- |
| 試產塗液     | 黃色「試產」標籤，寫上試產代號；放在調配室指定的試產櫃，不可與量產塗液混放 |
| 母卷批號     | 序號前加 T，例：C1-260912D-T01                                          |
| 母卷標籤     | 黃色試產標籤，寫上試產代號與「不得出貨」                                |
| 存放         | 試產品專用區（黃色定位線），不可放在量產待驗區                          |

## 7. 試產中

1. 開機前依產線的開機 SOP 完成檢查，條件改用「試產條件表」。
2. **每 50 m** 記錄一次：線速、各區烘箱溫度、張力、塗布量相關參數（CL-01 為 TH-01 厚度；CL-02 為凹版輥速比），以及線上檢測報警次數。
3. 參數調整只能由在場的 PE 決定，每次調整都要記錄時間、長度位置、調整前後數值。
4. 依試產條件表的取樣計畫取樣，交 QA 做首件檢驗；樣品標示試產代號、批號與長度位置。
5. 發生異常時，比照量產產品的異常代碼記錄（例如 D01），但**不依量產規定停線**，由 PE 與研發決定是否繼續。有安全疑慮時，任何人都可以緊急停機。

## 8. 試產後

1. 依換線 SOP 清潔，回到量產產品。
2. 剩餘試產塗液全部退回研發部，不可留在調配室。
3. 試產紀錄（參數紀錄表、異常紀錄、取樣清單）於**1 個工作天內**交給 PE，並副本給研發部。
4. 試產母卷由研發部決定處理方式（送樣、分析或報廢），製造部負責保管到研發部通知為止。

## 9. 禁止事項

- 把試產母卷移到量產待驗區或出貨區。
- 把試產塗液與量產塗液混用。
- 在交接簿、白板或量產紀錄上寫開發中產品的型號或配方內容。

## 1. 目的

清除微凹版塗布頭 CL02-GV-01 上的矽塗液。RF 系列塗液加入白金觸媒後會逐漸膠化，殘留在凹版輥網穴內的膠化物會造成塗佈量下降與條紋。

## 2. 適用範圍

只適用 CL-02（RF 系列）。CL-01 狹縫塗布頭請用 MFG-SOP-002，兩者溶劑不同：CL-02 用正庚烷，**不可使用 MEK**。

| 種類       | 時機                                                     | 所需時間   |
| ---------- | -------------------------------------------------------- | ---------- |
| 塗液盤清潔 | 每換一批塗液（最長 8 小時）；停機超過 30 分鐘              | 約 15 分鐘 |
| 完整清潔   | 換凹版輥時；每 72 小時；條紋經更換刮刀後仍未消失           | 約 90 分鐘 |

## 3. 所需工具、溶劑與防護具

| 項目       | 規格                                                         |
| ---------- | ------------------------------------------------------------ |
| 清潔溶劑   | CS-03（正庚烷清潔級）；塗液盤清潔約 3 L，完整清潔約 10 L       |
| 最終擦拭   | CS-01（IPA）                                                 |
| 刷具       | 尼龍軟毛刷（**禁止鋼刷**，會損傷網穴）                        |
| 浸泡槽     | 防爆浸泡槽（位於 CL-02 清潔間），容量 20 L                    |
| 檢查工具   | 50 倍攜帶式放大鏡                                            |
| 防護具     | 丁腈防溶劑手套、護目鏡、活性碳口罩                           |

正庚烷閃火點低於室溫，作業前確認防爆排氣運轉；浸泡槽使用後必須加蓋。

## 4. 塗液盤清潔步驟

1. 停止供液泵 CL02-PM-01，凹版輥維持 5 rpm 低速轉動。
2. 打開塗液盤排液閥，將殘液排入廢液桶。超過可使用時間（加觸媒後 8 小時）的塗液一律報廢，不可倒回調配槽。
3. 以 CS-03 沖洗塗液盤 2 次，每次約 1.5 L，排液。
4. 凹版輥轉動中，以無塵布沾 CS-03 輕壓在輥面 30 秒，再換乾淨的布重複 1 次。
5. 更換過濾袋 FC-10（每批塗液都要換）。
6. 接上新批塗液，循環 3 分鐘後才可恢復塗布。

## 5. 完整清潔步驟

1. 依 MFG-SOP-008 停機，關閉主電源並上鎖掛牌。
2. 鬆開刮刀座，取下刮刀片 DB-15，檢查刃口：
   - 有缺口、捲邊，或刮刀累計使用已達 40 萬公尺 → 更換新品。
   - 刃口正常 → 以 CS-03 擦拭後保留，並記錄目前累計公尺數。
3. 取下凹版輥（兩人作業，輥兩端握持，手不可接觸輥面）。
4. 將凹版輥放入防爆浸泡槽，以 CS-03 浸泡 20 分鐘。
5. 以尼龍軟毛刷**沿輥的圓周方向**刷洗，不可沿軸向來回刷。
6. 取出後以 CS-03 沖淋，再以 CS-01 沖淋，直立放在輥架上風乾 15 分鐘。
7. 以 50 倍放大鏡檢查網穴，至少檢查左、中、右 3 處：
   - 網穴堵塞面積 ≤ 5 %：合格。
   - 堵塞面積 > 5 %：重新浸泡刷洗 1 次；仍超過 5 % 時停用此輥，通報 PE 評估。
8. 清潔塗液盤與刮刀座，以 CS-01 最終擦拭。
9. 裝回凹版輥（確認輥端刻印的線數與產品相符：RF-12 為 GR-230、RF-25 為 GR-200、RF-50 為 GR-180），再裝回刮刀。

## 6. 檢查標準

| 項目           | 標準                                         |
| -------------- | -------------------------------------------- |
| 網穴堵塞       | 50 倍放大鏡下 ≤ 5 %                          |
| 刮刀刃口       | 無缺口、無捲邊；累計 < 40 萬公尺             |
| 塗液盤         | 白色無塵布擦拭無膠狀殘留                     |
| 復機後外觀     | 前 200 m 無 D01 條紋報警（CL02-IN-01）       |
| 復機後離型力   | 第一卷快速篩檢在判定範圍內（依 MFG-SOP-010） |

## 7. 異常時的處置

- 凹版輥掉落或碰撞：停止使用，通報 PE；不可目視判斷沒事就繼續用。
- 網穴內有硬化矽膠無法刷除：不可用溶劑以外的方式刮除，送 PE 處理。
- 溶劑潑灑超過 1 L：停止作業，依緊急應變程序處理。

## 8. 紀錄

- 「CL-02 塗布頭清潔紀錄」：清潔種類、凹版輥編號、網穴檢查結果、刮刀累計公尺數、作業者。
- 刮刀更換時，同步將刮刀計數器歸零，並寫在交接簿（見 MFG-RULE-002）。

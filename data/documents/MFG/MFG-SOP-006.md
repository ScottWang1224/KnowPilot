## 1. 目的

確保 CL-02 換線時凹版輥、基材、塗液與烘箱條件一起切換正確，並避免重離型產品的殘留塗液讓輕離型產品離型力偏高。

## 2. 適用範圍

CL-02 的 RF-12、RF-25、RF-50 互換。CL-01 換線請用 MFG-SOP-005。

## 3. 排程順序原則

**RF-12 → RF-25 → RF-50（輕 → 重）**

RF-25、RF-50 的塗液含離型力調整劑。由重離型換回輕離型時，只要管路或塗液盤殘留一點點，RF-12 的離型力就會偏高，所以由重換輕要多沖洗一次，並且第一卷快速篩檢合格前不放行。

## 4. 換線組合

| 由 → 至         | 凹版輥             | 基材               | 管路與塗液盤沖洗（CS-03） | 標準時間 |
| --------------- | ------------------ | ------------------ | ------------------------- | -------- |
| RF-12 → RF-25   | GR-230 → GR-200    | BF-P050 → BF-P075  | 1 次                      | 2 小時   |
| RF-25 → RF-50   | GR-200 → GR-180    | 不需要             | 1 次                      | 1.5 小時 |
| RF-50 → RF-25   | GR-180 → GR-200    | 不需要             | **2 次**                  | 2 小時   |
| RF-25 → RF-12   | GR-200 → GR-230    | BF-P075 → BF-P050  | **2 次**                  | 2.5 小時 |
| RF-50 → RF-12   | GR-180 → GR-230    | BF-P075 → BF-P050  | **2 次**                  | 2.5 小時 |
| RF-12 → RF-50   | GR-230 → GR-180    | BF-P050 → BF-P075  | 1 次                      | 2 小時   |

每次沖洗以 CS-03 約 5 L 循環 5 分鐘後排掉。

## 5. 作業步驟

1. 換線前 1 小時，班長確認新產品塗液已由調配組準備，並且**尚未加入觸媒**。觸媒在換線完成前 30 分鐘才加入，避免換線延誤消耗可使用時間。
2. 前一產品最後一卷收完，依 MFG-SOP-008 計畫停機，排空塗液盤。
3. 依第 4 節的次數沖洗供液管路與塗液盤，更換過濾袋 FC-10。
4. 拆下凹版輥：
   1. 主電源上鎖掛牌。
   2. 鬆開刮刀座，取下刮刀 DB-15。
   3. 鬆開兩端軸承座，兩人握持輥兩端取下（手不可接觸輥面）。
   4. 依 MFG-SOP-003 第 5 節清潔後，套上保護套放回輥架原位。
5. 安裝新凹版輥：
   1. 核對輥端刻印線數：RF-12 用 GR-230，RF-25 用 GR-200，RF-50 用 GR-180。
   2. 裝上軸承座，以千分錶量測輥面偏擺，**偏擺 ≤ 5 µm** 才合格；超過時重新安裝，第二次仍超過通報 PE。
   3. 裝回刮刀，確認計數器數值與刮刀實際累計相符。
6. 更換基材（需要時），以接紙方式帶過整條線。
7. 在控制面板選擇新產品配方，確認烘箱 5 區設定、線速、輥速比、收卷張力與錐度都切換為新產品條件（條件表見 MFG-SOP-004 第 4 節）。
8. 等待烘箱中段溫度穩定在新設定值 ± 5 °C。由低溫產品換高溫產品（例如 RF-12 → RF-50，第 3、4 區由 140 °C 升到 150 °C）約需 20 分鐘。
9. 依 MFG-SOP-004 第 3 節做開機前檢查後開機。

## 6. 換線後確認

| 項目               | 標準                                                   |
| ------------------ | ------------------------------------------------------ |
| 過渡段             | 開機後前 300 m 貼紅色標籤，切除報廢                     |
| 線上檢測           | 過渡段後 200 m 無條紋報警                              |
| 第一卷快速篩檢     | 在新產品的判定範圍內（RF-12 為 7–14 g/25mm、RF-25 為 18–28 g/25mm、RF-50 為 38–55 g/25mm） |
| 第一卷矽塗佈量     | QA 以 XRF 確認在新產品規格內                           |

由重換輕（第 4 節沖洗 2 次的組合）：第一卷快速篩檢結果出來前，後續所有卷都留在待判區。

## 7. 異常時的處置

- 換線後第一卷快速篩檢偏高：多半是前一產品殘留，停線，加做 1 次管路沖洗並更換塗液盤內塗液後重新開機，同時依 MFG-SOP-010 通報。
- 凹版輥偏擺持續超過 5 µm：可能是軸承磨損，停止換線，通報設備課。
- 新批塗液在換線完成前已加入觸媒且超過 6 小時：通知調配組評估，不足 2 小時可用時間的塗液不可開機。

## 1. 目的

讓 CL-01 在不同 HC 產品間換線時，基材、墊片、塗液與製程條件一次切換正確，並避免防眩粒子污染亮面產品。

## 2. 適用範圍

CL-01 的 HC-200、HC-350、HC-230AG 互換。CL-02 換線請用 MFG-SOP-006。

## 3. 排程順序原則

生管組排程時，同一週內盡量依以下順序生產：

**HC-200 → HC-350 → HC-230AG**

- 亮面產品（HC-200、HC-350）對異物最敏感，排在清潔後最前面。
- HC-230AG 含 3 µm 防眩微粒，換回亮面產品時必須拆解清潔並更換兩支濾芯，耗時最長，應排在一輪的最後。

## 4. 換線組合與作業內容

| 由 → 至               | 基材更換                | 墊片更換       | 塗布頭清潔     | 濾芯更換           | 標準時間 |
| --------------------- | ----------------------- | -------------- | -------------- | ------------------ | -------- |
| HC-200 → HC-350       | BF-P050 → BF-P125       | 100 → 150 µm   | 拆解清潔       | 不需要             | 4.5 小時 |
| HC-350 → HC-230AG     | BF-P125 → BF-P075       | 不需要         | 線上沖洗       | 不需要             | 1.5 小時 |
| HC-230AG → HC-200     | BF-P075 → BF-P050       | 150 → 100 µm   | 拆解清潔       | FC-05、FC-01 都換  | 5 小時   |
| HC-230AG → HC-350     | BF-P075 → BF-P125       | 不需要         | 拆解清潔       | FC-05、FC-01 都換  | 4.5 小時 |
| HC-350 → HC-200       | BF-P125 → BF-P050       | 150 → 100 µm   | 拆解清潔       | 不需要             | 4.5 小時 |
| HC-200 → HC-230AG     | BF-P050 → BF-P075       | 100 → 150 µm   | 拆解清潔       | 不需要             | 4.5 小時 |

塗布頭清潔方式見 MFG-SOP-002。

## 5. 作業步驟

1. **換線前 1 小時**：班長確認下一工單的基材、塗液已備妥，塗液已完成調配並有黏度、固含量合格紀錄。
2. 前一產品最後一卷收卷完成，依 MFG-SOP-007 計畫停機。
3. 將供液管路中的前一產品塗液回收至原塗液桶並標示「回收」，交調配組判定可否再用。
4. 依第 4 節表格執行塗布頭清潔、墊片與濾芯更換。
5. 更換基材：以接紙膠帶將新基材接在舊基材尾端，由舊基材帶過整條線。
6. 在控制面板選擇新產品配方，確認以下設定自動切換到新值：

| 項目               | HC-200            | HC-350            | HC-230AG          |
| ------------------ | ----------------- | ----------------- | ----------------- |
| 線速               | 20 m/min          | 15 m/min          | 18 m/min          |
| 烘箱 OV-01／02／03  | 60／80／90 °C     | 60／85／95 °C     | 55／75／90 °C     |
| UV 累積光量        | 400 ± 50 mJ/cm²   | 600 ± 50 mJ/cm²   | 450 ± 50 mJ/cm²   |
| UV 區氧濃度        | ≤ 1,000 ppm       | ≤ 300 ppm         | ≤ 1,000 ppm       |
| 電暈功率           | 1.2 kW            | 1.5 kW            | 1.2 kW            |
| 收卷張力／錐度     | 90 N／25 %        | 120 N／20 %       | 100 N／25 %       |

7. 烘箱溫度需要下降時（例如 HC-350 → HC-230AG 第 1 區由 60 °C 降到 55 °C），等實際溫度進入 ± 5 °C 才能開始塗布。
8. 依 MFG-SOP-001 第 4 節完成開機前檢查（換線後也要做），其中 UV 光量要以新產品標準重新量測。
9. 開機，換線後的前 150 m 為過渡段，貼紅色標籤並切除報廢。

## 6. 檢查標準

- 換線後第一卷依 MFG-SOP-001 第 6 節送首卷檢驗。
- HC-230AG 換回亮面產品後的第一卷，QA 會加做霧度檢查：HC-200 霧度 ≤ 0.8 %、HC-350 霧度 ≤ 1.0 %。霧度超標代表防眩微粒殘留，該卷待判。
- CL01-IN-01 前 150 m 過渡段以外不得有異物連續報警。

## 7. 異常時的處置

- 換線時間超過標準時間 1 小時以上：班長通知生管組調整後續排程。
- 配方切換後設定值不正確：停止換線，通報 PE，不得手動輸入參數。
- 換線後條紋：依 MFG-SOP-009。

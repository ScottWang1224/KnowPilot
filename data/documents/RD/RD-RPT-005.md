## 1. 背景

BF-P050 目前只有 V01 一家供應商，用於 HC-200 與 RF-12。採購課要求建立第二來源以降低斷料風險，V08 為候選供應商，2026-07 提供樣品 3 批。

## 2. 基材特性比較

| 項目                     | V01（現用）  | V08 批 1     | V08 批 2     | V08 批 3     | QA 進料規格        |
| ------------------------ | ------------ | ------------ | ------------ | ------------ | ------------------ |
| 厚度（µm）                | 50.2         | 50.6         | 49.8         | 50.9         | 50 ± 3 %            |
| 霧度（%）                 | 0.38         | 0.52         | 0.49         | 0.55         | ≤ 0.6              |
| 透光率（%）               | 90.4         | 90.1         | 90.2         | 90.0         | ≥ 89.5             |
| 表面張力（dyn/cm）        | 44           | 42           | 42           | 43           | ≥ 42               |
| 熱收縮 150 °C 30 分 MD（%）| 1.0          | 1.3          | 1.2          | 1.4          | （無規格）         |
| 凝膠點 ≥ 100 µm（個/m²）   | 0.1          | 0.3          | 0.2          | 0.4          | （燈箱目視）       |

V08 三批都符合進料規格，但霧度與熱收縮都比 V01 高，且批間差異較大。

## 3. HC-200 實驗室塗布（FM-HC-021 R4）

| 項目         | V01         | V08（3 批平均） | HC-200 規格 |
| ------------ | ----------- | --------------- | ----------- |
| 霧度         | 0.42 %      | 0.61 %          | ≤ 0.8 %     |
| 透光率       | 91.8 %      | 91.4 %          | ≥ 91.0 %    |
| 鉛筆硬度     | 2H          | 2H              | ≥ 2H        |
| 密著性       | 5B          | 5B              | 5B          |

霧度仍在規格內，但餘裕從 0.38 % 縮小到 0.19 %，PE 製程能力報告中 HC-200 霧度 Cpk 會由約 1.8 降到約 1.0。**不建議用於 HC-200**。

## 4. RF-12 實驗室塗布（FM-RF-012 R2，主固化區 140 °C）

| 項目               | V01            | V08（3 批平均）  | RF-12 規格      |
| ------------------ | -------------- | ---------------- | --------------- |
| 離型力（20 小時）   | 11.8 g/25mm    | 12.4 g/25mm      | 8–16 g/25mm     |
| 殘餘接著率         | 93 %           | 92 %             | ≥ 85 %          |
| 矽塗佈量           | 0.101 g/m²     | 0.103 g/m²       | 0.10 ± 0.02     |
| 擦拭脫落           | 無             | 無               | 無脫落          |

RF-12 用途（客戶 D 被動元件載體、客戶 E 光學膠）對霧度沒有要求；熱收縮較高需要確認 CL-02 烘箱 140 °C 下的寬幅收縮與平整度。

## 5. 結論

1. V08 基材**有條件可用於 RF-12**：需在 CL-02 量產線試產 1 次（至少 3 卷），確認收縮、平整度與收卷。
2. **不建議用於 HC-200**（霧度餘裕不足）。
3. 若採用，屬原料供應商變更，需一級 ECN 並通知客戶 D、E。

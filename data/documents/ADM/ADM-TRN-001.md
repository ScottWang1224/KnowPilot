## 1. 公司簡介

智塗精密材料股份有限公司成立於 2009 年，位於台中市精材工業區，員工約 300 人，專注於卷對卷精密塗布。

| 產線  | 塗布方式   | 產品                                       |
| ----- | ---------- | ------------------------------------------ |
| CL-01 | 狹縫塗布   | HC 系列光學硬塗膜：HC-200、HC-350、HC-230AG |
| CL-02 | 微凹版塗布 | RF 系列離型膜：RF-12、RF-25、RF-50          |

部門：製造部（MFG）、製程工程部（PE）、品質保證部（QA）、研發部（RD）、行政管理部（ADM）。

## 2. 到職第一天

| 時間        | 內容                                          | 負責       |
| ----------- | --------------------------------------------- | ---------- |
| 08:00–09:00 | 報到、員工證、置物櫃、工作服與安全鞋          | 人資課     |
| 09:00–10:00 | 帳號啟用、密碼設定、雙因素驗證                | 資訊課     |
| 10:00–12:00 | 員工工作規則、請假與加班、福利                | 人資課     |
| 13:00–16:00 | 一般安全衛生教育訓練（法定 3 小時）           | 環安衛     |
| 16:00–17:00 | 部門報到，主管說明工作內容與帶訓人            | 所屬部門   |

## 3. 第一週必修

| 課程                           | 時數   | 對象                           | 文件                |
| ------------------------------ | ------ | ------------------------------ | ------------------- |
| 資訊安全                       | 1 小時 | 全體                           | ADM-RULE-002        |
| 緊急應變與疏散演練路線         | 1 小時 | 全體                           | ADM-SOP-001         |
| 危害性化學品通識               | 3 小時 | 製造、PE、QA、RD               | ADM-SOP-002         |
| 潔淨室進出                     | 0.5 小時 | 需進入塗布區者               | MFG-RULE-001        |
| 品質異常通報總則               | 1 小時 | 全體                           | QA-RULE-001         |
| 文件與紀錄管理                 | 1 小時 | 全體                           | QA-RULE-002         |

課程在教育訓練系統報名，完成後系統自動記錄。

## 4. 第一個月

- 部門專業訓練由各部門安排。製造部新進操作員須依製造部技能檢定制度取得資格後，才能單獨執行作業；詳細內容請洽製造部。
- 第 30 天由主管進行到職面談，確認訓練進度。

## 5. 使用知識平台 KnowPilot

1. 用公司帳號登入，可以查詢公司公告與文件，也可以直接用口語提問。
2. **你只會看到全公司文件與自己部門的文件**。其他部門的文件查不到是正常的；需要時向文件負責部門詢問。
3. 平台回答時會附上來源文件編號，作業前請以原文件確認版本。
4. 問題缺少關鍵資訊時（例如沒有說是哪一條產線），平台會先反問，請補充後再查。

## 6. 試用期

新進正職人員試用期 3 個月。試用期滿前 2 週，主管依訓練完成情況與工作表現評核，送人資課。

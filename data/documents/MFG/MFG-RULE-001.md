## 第 1 條 適用範圍

本規範適用所有需要進入塗布區的人員，包括製造部、製程工程部、品質保證部、研發部、行政管理部同仁，以及訪客與承攬商。

兩條塗布線的潔淨等級不同，更衣規定也不同：

| 區域          | 潔淨等級       | 適用規定      |
| ------------- | -------------- | ------------- |
| CL-01 塗布區  | Class 1,000    | 第 4 條       |
| CL-02 塗布區  | Class 10,000   | 第 5 條       |

塗布區以外的調配室、倉庫、辦公區不需要更衣。

## 第 2 條 進入資格

1. 製造部塗布課人員：完成潔淨室訓練後，門禁卡開通對應產線。
2. 其他部門同仁：完成線上「潔淨室進出訓練」（30 分鐘，於教育訓練系統報名），由所屬主管申請門禁權限。
3. 訪客與承攬商：依 ADM-SOP-005 申請，**全程由本公司人員陪同**，不開通門禁卡。
4. 有發燒、咳嗽、皮膚脫屑嚴重等狀況，當天不得進入 CL-01 塗布區。

## 第 3 條 共同規定

1. 進入前在更衣室外脫下外套、取下手錶與首飾，放入置物櫃。
2. 禁止化妝（粉底、蜜粉、睫毛膏）及使用髮膠。
3. 可攜帶物品：無塵筆、無塵紙、經擦拭的手機（放在無塵袋內）。**一般紙張、紙箱、原子筆不可帶入**。
4. 更衣順序：由上往下 — 頭罩或帽子 → 口罩 → 無塵衣 → 鞋套或無塵鞋 → 手套。
5. 經過風淋室時，站在中央，雙手舉起慢慢轉身。
6. 離開時，無塵衣掛回指定掛鉤；一次性用品（鞋套、口罩、手套）丟入專用回收桶。

## 第 4 條 CL-01 塗布區（Class 1,000）

| 項目       | 規定                                          |
| ---------- | --------------------------------------------- |
| 服裝       | **連身**無塵衣（含頭罩，只露出眼睛）          |
| 口罩       | 必須，完全蓋住口鼻                            |
| 鞋         | 無塵鞋（專用，不可穿出塗布區）                |
| 手套       | 雙層：內層棉質、外層丁腈                      |
| 風淋       | **30 秒**                                     |
| 無塵衣更換 | 每週送洗一次；有污損立即更換                  |
| 停留人數   | 塗布區同時最多 8 人                           |

## 第 5 條 CL-02 塗布區（Class 10,000）

| 項目       | 規定                                          |
| ---------- | --------------------------------------------- |
| 服裝       | 無塵**外套** + 無塵帽                         |
| 口罩       | 必須                                          |
| 鞋         | 鞋套（一次性，可套在一般工作鞋外）            |
| 手套       | 單層丁腈                                      |
| 風淋       | **15 秒**                                     |
| 無塵衣更換 | 每週送洗一次                                  |
| 停留人數   | 塗布區同時最多 10 人                          |

> 從 CL-02 直接前往 CL-01，必須回到更衣室依第 4 條重新更衣，不可直接穿 CL-02 的服裝進入 CL-01。

## 第 6 條 塗布區內的行為

1. 不可奔跑、不可在塗布區內進食或喝水。
2. 不可觸摸生產中的基材與塗布頭。
3. 不可自行開關任何設備或閥門。
4. 塗布區使用易燃溶劑，禁止任何火源；化學品相關規定見 ADM-SOP-002。
5. 進出塗布區的門開啟後要儘快關上，不可長時間開門搬運物品。

## 第 7 條 違規處理

1. 第一次違規：當場糾正，通知所屬主管。
2. 同一年內第二次違規：暫停門禁權限 1 個月，重新完成訓練後恢復。
3. 違規造成產品異物不良：依員工工作規則（ADM-RULE-001）懲處。

## 第 8 條 其他

塗布區的清潔方式、粒子數管制與異物處理屬於製造部作業規定，詳細內容請洽製造部。

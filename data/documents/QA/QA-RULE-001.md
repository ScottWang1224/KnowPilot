## 第 1 條 目的

讓任何人發現品質異常時，都知道要通報誰、多快通報、不能做什麼。

## 第 2 條 適用範圍

全體員工。任何部門的同仁發現產品、物料或紀錄異常，都有通報義務。

## 第 3 條 異常等級

| 等級 | 定義                                             | 處理原則                       | 通報時限 |
| ---- | ------------------------------------------------ | ------------------------------ | -------- |
| A    | 可能影響產品功能、可能整批不良或流出至客戶       | 立即停止生產或作業；隔離       | 15 分鐘  |
| B    | 局部不良，可標示切除，不影響功能                 | 標示、隔離不良部分，持續監控   | 1 小時   |
| C    | 輕微，或在規格內但有變差趨勢                     | 記錄，班別交接                 | 當班     |

- 同一種異常在同一班內出現第 3 次 B 級，升為 A 級。
- 異常代碼（D01–D11）與各代碼的判定標準由品質保證部制定，現場作業的處置方式由製造部規定。詳細內容請洽品質保證部或製造部。
- 判定有疑義時，以品質保證部判定為準。

## 第 4 條 通報

1. 發現者先通知**當班班長**（非生產單位通知直屬主管）。
2. 班長依等級通報：A 級通報課長、QA 值班、PE 值班；B 級通報 QA 值班。
3. 夜間與假日：PE 以電話通報；課長不在時通報值日主管。
4. A 級在 **30 分鐘內**開立異常通報單（編號 AR-日期-序號，夜班以上班日為日期）。

## 第 5 條 不良品隔離

1. 可疑品貼黃色「待判」標籤，放在待判區。
2. 判定不良的貼紅色「隔離」標籤，放在紅色區。
3. 隔離品只有 QA 可以解除；**不得自行切除、重新收卷、更換標籤來掩蓋異常**。

## 第 6 條 批次追溯

每一卷產品都必須能追溯到：

| 項目         | 例                                      |
| ------------ | --------------------------------------- |
| 母卷批號     | 線別-上班日期班別-序號                  |
| 工單         | WO-年月-序號                            |
| 原物料批號   | 基材、塗液批號                          |
| 設備與條件   | 產線、當時的設備紀錄                    |
| 作業人員     | 操作員、班長                            |
| 檢驗結果     | IPQC、OQC 紀錄                          |

追溯資料由各部門依自己的紀錄規定保存，保存期限依文件與紀錄管理辦法（QA-RULE-002）。

## 第 7 條 紀錄保全

1. 發生異常後，相關紀錄（生產紀錄、檢驗紀錄、設備趨勢）**不得修改、刪除或補寫**。
2. 紀錄寫錯時，依規定畫線更正並簽名註明原因。
3. 竄改紀錄依員工工作規則以大過論處。

## 第 8 條 客訴

客戶的品質抱怨一律轉給品質保證部受理。業務、製造、工程、研發人員不直接對客戶說明品質問題的原因或對策。

本文件為虛構企業展示資料，內容與數值不得用於真實生產。

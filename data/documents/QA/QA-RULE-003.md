## 1. 品質政策

> **每一層都精準，每一卷都可追溯。**
>
> 我們以穩定的製程、確實的檢驗與誠實的紀錄，提供客戶一致可靠的精密塗布材料；發現問題時，先保護客戶，再找出根本原因，不讓同樣的問題發生第二次。

依 ISO 9001 要求，**全體員工都應了解並能說明品質政策**。內部稽核時，稽核員可能詢問任何一位員工。

### 品質政策的三個重點

| 重點         | 意思                                                       | 每個人可以做的事                         |
| ------------ | ---------------------------------------------------------- | ---------------------------------------- |
| 精準         | 依照文件作業，不憑感覺調整                                 | 作業前確認文件是現行版本                 |
| 可追溯       | 每一卷產品都能查到原料、設備、人員與檢驗紀錄               | 紀錄即時、照實填寫，不補寫、不竄改       |
| 先保護客戶   | 有疑慮的產品先隔離，不讓可疑品流出                         | 發現異常立即通報，不自行判斷「應該沒事」 |

## 2. 2026 年品質目標

| 目標                                         | 負責部門           |
| -------------------------------------------- | ------------------ |
| 重大客訴每年不超過 3 件                      | 全公司，QA 統計    |
| 8D 報告 D1–D4 在 10 個工作天內完成率 100 %    | 品質保證部         |
| 主要品質特性的製程能力全部達到公司標準       | 製程工程部         |
| 量測儀器校正逾期 0 件                        | 品質保證部         |
| 員工品質相關訓練完成率 100 %                  | 行政管理部人資課   |

目標達成狀況每月在品質會議報告，每半年由總經理主持管理審查。

## 3. 品質系統如何運作

| 機制           | 說明                                                                   | 負責             |
| -------------- | ---------------------------------------------------------------------- | ---------------- |
| 文件管理       | 規章、SOP、規格都經過核准，只用現行版本                                | 品質保證部       |
| 製程變更管理   | 製程條件、原料、設備的永久變更都要經過評估、驗證與核准                 | 製程工程部       |
| 異常通報       | 異常分 A、B、C 三級，依等級在時限內通報                               | 全體             |
| 矯正措施（8D） | 重大異常與客訴以 8D 方法找出發生與流出的根本原因並防止再發             | 品質保證部       |
| 內部稽核       | 每年依 ISO 9001 稽核各部門，由取得資格的內部稽核員執行                 | 品質保證部       |
| 管理審查       | 每半年檢討品質目標、客訴、稽核結果與資源需求                           | 總經理           |

ISO 9001 證書將於 2027 年 3 月到期，2027 年初進行重新驗證。

## 4. 三段檢驗的分工

產品從原料到出貨，要通過三道檢驗：

| 檢驗   | 全名                         | 什麼時候               | 目的                                     | 負責       |
| ------ | ---------------------------- | ---------------------- | ---------------------------------------- | ---------- |
| IQC    | 進料檢驗                     | 原物料到貨後、使用前   | 不讓有問題的原料進入生產                 | 品質保證部 |
| IPQC   | 製程巡檢                     | 生產過程中             | 及早發現製程偏移，減少不良品             | 品質保證部（製造部配合取樣） |
| OQC    | 出貨檢驗                     | 每一卷出貨前           | 確認產品符合客戶規格，合格才放行         | 品質保證部 |

- 檢驗項目與判定標準依產品而不同，由品質保證部的檢驗規範規定；詳細內容請洽品質保證部。
- 出貨放行由品質保證部簽核；不合格品不得出貨，需要特殊處理時由 QA 經理決定並經客戶同意。
- 製造部是品質的第一線：開機檢查、巡檢、異常通報都由製造部執行，QA 負責判定與把關。

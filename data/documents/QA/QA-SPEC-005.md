## 1. 等級定義

| 等級 | 定義                                             | 現場動作                       | 通報時限 |
| ---- | ------------------------------------------------ | ------------------------------ | -------- |
| A    | 影響產品功能，或可能整卷不良、流出至客戶         | 立即停線；不良段隔離           | 15 分鐘  |
| B    | 局部不良，可標示切除；功能不受影響               | 不停線；標示不良段，持續監控   | 1 小時   |
| C    | 輕微、位於修邊區，或規格內的趨勢異常             | 記錄於生產日報，班別交接       | 當班     |

共通規則：

1. 同一代碼、同一產線、同一班內第 3 次 B 級，升為 A 級。
2. A 級在 30 分鐘內開立異常通報單（AR 單）。
3. 有效寬度為 1,300 mm，兩側各 25 mm 為修邊區。修邊區內的瑕疵一律最高判 C 級（D09、D10 除外）。
4. 現場與 QA 判定不同時，以 QA 判定為準。

## 2.1 D01 條紋（HC、RF）

| 等級 | 條件                                                         |
| ---- | ------------------------------------------------------------ |
| A    | 有效寬度內連續長度 > 2 m；或處置後仍持續出現                 |
| B    | 有效寬度內、間歇出現，單段 ≤ 2 m                              |
| C    | 只在修邊區                                                   |

確認：燈箱下以 45° 斜光觀察；HC 加測條紋處與正常處的厚度差。通報：班長、課長、QA 值班、PE 值班。

## 2.2 D02 針孔（HC、RF）

| 等級 | 條件                     |
| ---- | ------------------------ |
| A    | 密度 > 3 個/m²           |
| B    | 1–3 個/m²                |
| C    | < 1 個/m²                |

通報：班長、QA 值班。

## 2.3 D03 異物／顆粒（HC、RF）

| 等級 | HC 系列                                         | RF 系列                                    |
| ---- | ----------------------------------------------- | ------------------------------------------ |
| A    | ≥ 100 µm 任一顆                                 | ≥ 200 µm 任一顆                            |
| B    | 50–100 µm，> 2 顆/m²                             | 150–200 µm，> 2 顆/m²                       |
| C    | 50–100 µm，≤ 2 顆/m²                             | 150–200 µm，≤ 2 顆/m²                       |

確認：LB-MS-01 量測尺寸；A 級樣品送實驗室 FTIR 分析（結果彙整於 QA-RPT-001）。通報：班長、QA 值班。

## 2.4 D04 縮孔（HC、RF）

| 等級 | 條件                                       |
| ---- | ------------------------------------------ |
| A    | 密度 > 1 個/m²，或任一直徑 ≥ 1 mm          |
| B    | ≤ 1 個/m²，直徑 0.3–1 mm                   |
| C    | 直徑 < 0.3 mm 零星出現                     |

通報：班長、QA 值班、PE 值班（縮孔常與基材或塗液污染有關）。

## 2.5 D05 橘皮（HC）

| 等級 | 條件                                     |
| ---- | ---------------------------------------- |
| A    | 燈箱目視可見且面積 > 10 %                 |
| B    | 可見，面積 ≤ 10 %                         |
| C    | 只在斜光下勉強可見                       |

通報：班長、PE 值班。

## 2.6 D06 皺摺（HC、RF）

| 等級 | 條件                                     |
| ---- | ---------------------------------------- |
| A    | 壓痕摺（折痕無法展平）                   |
| B    | 可展平的波浪皺，長度 > 1 m                |
| C    | 可展平，長度 ≤ 1 m                        |

通報：班長、課長。

## 2.7 D07 刮傷（HC、RF）

| 等級 | 條件                                                        |
| ---- | ----------------------------------------------------------- |
| A    | 連續刮傷 > 1 m；或 HC 塗層面任何燈箱可見的刮傷               |
| B    | RF：可見刮傷 ≤ 1 m                                            |
| C    | 只在基材背面、不影響功能                                    |

通報：班長、QA 值班。

## 2.8 D08 厚度不均（HC、RF）

| 等級 | HC 系列（橫向厚度偏差）     | RF 系列（矽塗佈量）           |
| ---- | --------------------------- | ----------------------------- |
| A    | 任一點偏離目標 > ± 15 %      | 超出產品規格                  |
| B    | ± 10–15 %                    | 在規格內但偏離目標 > 15 %      |
| C    | ± 5–10 % 的趨勢              | —                             |

通報：班長、PE 值班、QA 值班。

## 2.9 D09 離型力異常（RF）

分兩種判定，數值範圍不同，不可混用：

| 量測                 | 用途           | 判定範圍              | B 級                 | A 級                 |
| -------------------- | -------------- | --------------------- | -------------------- | -------------------- |
| 快速篩檢             | 線上停線       | RF-12 7–14、RF-25 18–28、RF-50 38–55 g/25mm | 超出範圍 20 % 以內 | 超出 20 % 以上 |
| 20 小時量測          | 出貨判定       | RF-12 8–16、RF-25 20–30、RF-50 42–58 g/25mm | 超出範圍 20 % 以內 | 超出 20 % 以上，或殘餘接著率 < 85 % |

預設等級 B；詳細界限見 QA-SPEC-003 第 4 節與 QA-SOP-002。通報：班長、課長、QA 值班、PE 值班。

## 2.10 D10 硬度不足（HC）

鉛筆硬度低於產品規格（HC-200、HC-230AG < 2H；HC-350 < 3H），**一律 A 級**。

確認：以 LB-PH-01 依 JIS K5600-5-4、750 g 荷重量測；不合格時再用低一級鉛筆確認實際等級。單卷不合格時，同工單其他卷全數重測。

通報：班長、課長、QA 值班、PE 值班。

## 2.11 D11 收卷不良（HC、RF）

| 等級 | 條件                                            |
| ---- | ----------------------------------------------- |
| A    | 端面錯位 > 10 mm（望遠鏡狀），或內層鬆捲        |
| B    | 端面錯位 3–10 mm                                |
| C    | 鬆捲但可重新收卷                                |

端面錯位 < 3 mm 屬正常。通報：班長、課長。

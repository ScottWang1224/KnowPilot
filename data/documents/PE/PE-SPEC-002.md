## 1. 適用範圍

- 產品：HC-350 高硬度光學硬塗膜，基材 BF-P125（厚基材）。主要客戶：客戶 B（觸控面板）。
- 產線：CL-01。

## 2. 產品品質目標

| 項目         | 規格         |
| ------------ | ------------ |
| 塗層乾膜厚度 | 5.0 ± 0.5 µm |
| 鉛筆硬度     | ≥ 3H         |
| 霧度         | ≤ 1.0 %      |
| 全光線透光率 | ≥ 90.5 %     |
| 密著性       | 5B           |

## 3. 與 HC-200 的主要差異

1. **低氧固化**：3H 硬度需要較完整的表面固化，UV 區氧濃度必須 ≤ 300 ppm，HC-200 只要 ≤ 1,000 ppm。氮氣流量需求約為 HC-200 的 2.5 倍。
2. **較高 UV 光量**：600 mJ/cm²，線速因此降到 15 m/min。
3. **厚塗層**：墊片 150 µm、塗布間隙 90 µm（HC-200 為 60 µm），濕膜 11.1 µm，乾燥負荷較大，第 2、3 區溫度比 HC-200 各高 5 °C。
4. **厚基材**：125 µm 基材剛性高，收卷張力提高到 120 N，錐度降到 20 %。

## 5. 注意事項

1. 線速**不可**提高到 16 m/min 以上：光量會低於 560 mJ/cm²，加上燈管衰減很容易低於下限。
2. 氧濃度超過 300 ppm 時，鉛筆硬度通常降到 2H，屬於 D10 硬度不足，必須停線。氧濃度偏高時先檢查氮氣供應壓力（≥ 0.4 MPa）與 UV 區入口的遮簾是否破損。
3. HC-350 對異物最敏感（客戶 B 用於觸控面板表面）。2026-04 曾發生異物客訴，生產 HC-350 前務必確認 FFU 壓差紀錄與塗布區粒子數。

## 6. 超出規格時的處置

與 PE-SPEC-001 第 5 節相同。另外：

| 狀況                    | 處置                                    |
| ----------------------- | --------------------------------------- |
| UV 光量低於 550 mJ/cm²  | 停線，通報 PE 值班確認燈管              |
| 氧濃度 > 300 ppm        | 停線，檢查氮氣；恢復前生產段待判        |

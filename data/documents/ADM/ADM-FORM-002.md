## 1. 出差申請單

位置：人事系統 →「出差」→「出差申請」。

| 欄位               | 說明                                                       |
| ------------------ | ---------------------------------------------------------- |
| 出差類別           | 國內／國外（決定核准層級與費用標準）                       |
| 出差地點           | 城市；國外寫國家與城市                                     |
| 起訖日期與時間     | 實際出發與返回時間（影響日支費半日或全日）                 |
| 事由               | 拜訪對象（客戶以代號填寫，例如客戶 B）與目的               |
| 交通方式           | 高鐵、自行開車、公務車、飛機等；自行開車需填預估里程       |
| 住宿               | 預計住宿晚數                                               |
| 預支               | 國外出差可申請預支（日支費與住宿合計的 80 %）               |
| 職務代理人         | 必填；輪班人員填代班安排                                   |

核准後系統會通知行政管理部；國外出差的機票由行政管理部代訂。

## 2. 出差報支單

位置：人事系統 →「出差」→「報支」，選擇已核准的出差申請單帶入。

| 欄位           | 說明                                                         |
| -------------- | ------------------------------------------------------------ |
| 交通費         | 逐筆填寫日期、起訖地點、金額；附票根或電子票證明             |
| 自行開車       | 填實際里程，系統以每公里 4 元計算                            |
| 住宿費         | 每晚金額；超過上限時填寫說明與核准人                         |
| 日支費         | 系統依地區與天數自動計算，不需自行填寫                       |
| 被招待餐次     | 有客戶或供應商招待用餐時填寫，系統自動扣減                   |
| 其他           | 簽證費、保險、樣品運費等；說明用途                           |
| 預支沖銷       | 系統自動帶入已預支金額                                       |

## 3. 應附單據

1. 收據或統一發票，抬頭：智塗精密材料股份有限公司，含統一編號。
2. 國外收據：附信用卡簽單或刷卡紀錄；外幣以刷卡當日匯率換算，或以出發日台灣銀行賣出匯率計算。
3. 電子單據上傳 PDF 或照片；紙本正本於報支後 3 個工作天內交行政管理部。

## 4. 常見退件原因

| 原因                                 | 正確做法                                     |
| ------------------------------------ | -------------------------------------------- |
| 收據沒有統一編號                     | 結帳時告知統一編號；無法補開者附說明         |
| 住宿超過上限但沒有事先核准           | 超出部分自付，或附部門經理事先同意的紀錄     |
| 超過 10 個工作天才報支               | 填寫逾期說明，部門經理核准                   |
| 計程車費沒有說明原因                 | 說明（深夜、攜帶樣品、無大眾運輸）           |
| 日支費自行加計                       | 日支費由系統計算                             |

## 5. 範例

QA 品保工程師至台北拜訪客戶 B，當日往返，搭高鐵：

| 項目     | 金額               |
| -------- | ------------------ |
| 高鐵來回 | 1,400 元（附票根）  |
| 捷運     | 60 元              |
| 日支費   | 400 元（當日往返） |
| 合計     | 1,860 元           |

## 1. 目的

讓每一個研發樣品都能追溯到配方版本、製作條件與測試結果，並防止樣品或資料未經授權離開研發部。

## 2. 樣品編號

格式：**RS-年月-序號**（例：RS-2609-014，2026 年 9 月第 14 號樣品）。

- 序號每月從 001 起算，由樣品登錄系統自動產生，不可手寫自編。
- 同一次塗布的不同條件段，用同一個編號加段號：RS-2609-014-A、RS-2609-014-B。
- 在量產線試產取得的樣品，另外記錄試產代號與母卷批號（例：NP-2026-02、C1-260912D-T01）。

## 3. 登錄欄位

| 欄位               | 說明                                             |
| ------------------ | ------------------------------------------------ |
| 樣品編號           | 系統產生                                         |
| 專案               | 專案代號或試產代號                               |
| 配方               | 配方編號與版本（例：FM-HC-041 R2）                |
| 基材               | 品號與批號                                       |
| 製作條件           | 塗布設備、速度、乾燥與固化條件                   |
| 製作者、日期       |                                                  |
| 數量               | 片數或長度                                       |
| 存放位置           | 樣品櫃編號                                       |
| 用途               | 內部測試／送客戶／送外部實驗室                   |

## 4. 存放

| 樣品類型         | 條件                          | 保存期限                 |
| ---------------- | ----------------------------- | ------------------------ |
| HC 系列膜片      | 23 ± 5 °C，避光                | 專案結束後 1 年          |
| RF 系列膜片      | 23 ± 5 °C，離型面朝內收存      | 專案結束後 1 年          |
| 塗液樣品         | 防爆冰箱 5 °C                  | 依塗液可使用時間，最長 3 個月 |
| 送客戶樣品留底   | 同上                          | 3 年                     |

RF 塗液加入觸媒後不保存，當天用完或報廢。

## 5. 測試紀錄

1. 每項測試記錄：測試目的、方法（引用 QA 方法時寫明版本）、儀器編號、條件、原始結果、判讀者。
2. 使用 LB-PT-02 等共用儀器時，確認校正標籤在有效期內。
3. 原始數據（剝離曲線、光譜）存放在研發部伺服器的專案資料夾，**不可存放在個人電腦或外接硬碟**。
4. 不同版本的測試方法得到的數據，不可放在同一張圖表中比較，除非註明。
5. 結論與原始數據分開記錄：結論寫在實驗紀錄本，原始數據以樣品編號連結。

## 6. 樣品送出

| 送出對象         | 核准                 | 規定                                             |
| ---------------- | -------------------- | ------------------------------------------------ |
| 公司內其他部門   | 研究員               | 只附樣品編號與測試目的，不附配方資訊             |
| 客戶             | 研發部經理           | 經業務與 QA 確認；樣品標籤只寫樣品代號            |
| 外部實驗室       | 研發部經理           | 需簽保密協議；不提供配方                         |

送出時登錄送出日期、對象、數量與核准人。

## 7. 報廢

1. 超過保存期限的樣品，每季由葉冠廷整理清單，研發部經理核准後報廢。
2. 塗液樣品依化學品廢棄程序處理。
3. 送客戶樣品留底不得提前報廢。

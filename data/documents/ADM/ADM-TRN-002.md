## 1. 公司簡介

智塗精密材料股份有限公司成立於 2009 年，位於台中市精材工業區，是一家**精密塗布**材料廠，員工約 300 人。

我們的工作，是在一卷很長的透明塑膠薄膜（PET 基材）上，均勻塗上一層非常薄的功能性塗層，讓薄膜具備新的功能，例如表面更耐刮，或者能讓黏膠輕鬆撕離。這種邊放卷、邊塗布、邊收卷的連續生產方式稱為**卷對卷（Roll-to-Roll）**。

公司通過 ISO 9001 品質管理系統與 ISO 14001 環境管理系統驗證。

## 2. 兩大產品系列

| 系列 | 中文名稱       | 做什麼用                                                         | 生產線 |
| ---- | -------------- | ---------------------------------------------------------------- | ------ |
| HC   | 光學硬塗膜     | 貼在顯示器、觸控面板表面，保護螢幕不被刮傷，同時保持清晰透光     | CL-01  |
| RF   | 離型膜         | 當作膠帶、光學膠、電子元件製程中的「保護底紙」，用的時候撕掉即可 | CL-02  |

### 2.1 HC 系列（光學硬塗膜）

| 型號     | 特色                       | 主要用途                         | 客戶類型       |
| -------- | -------------------------- | -------------------------------- | -------------- |
| HC-200   | 亮面、清晰透光             | 顯示器模組表面保護               | 顯示器模組廠   |
| HC-350   | 高硬度、更耐刮             | 觸控面板表面保護                 | 觸控面板廠     |
| HC-230AG | 防眩（霧面），減少反光     | 戶外或強光環境使用的顯示器       | 顯示器模組廠   |

### 2.2 RF 系列（離型膜）

離型膜的重點是「撕開時要用多少力」，數字越大越不容易撕開。三個型號依撕開的輕重區分：

| 型號  | 特色     | 主要用途                                         | 客戶類型                   |
| ----- | -------- | ------------------------------------------------ | -------------------------- |
| RF-12 | 輕離型   | 被動元件製程載體、光學膠保護膜                   | 被動元件廠、光學膠廠       |
| RF-25 | 中離型   | 工業膠帶、光學膠                                 | 工業膠帶廠、光學膠廠       |
| RF-50 | 重離型   | 需要較牢固貼合、不易自己脫落的工業膠帶           | 工業膠帶廠                 |

各型號的詳細規格與檢驗標準由品質保證部管理，製程條件由製程工程部管理。

## 4. 生產線

| 產線  | 塗布方式   | 生產產品 | 潔淨等級     |
| ----- | ---------- | -------- | ------------ |
| CL-01 | 狹縫塗布   | HC 系列  | Class 1,000  |
| CL-02 | 微凹版塗布 | RF 系列  | Class 10,000 |

廠內只有這兩條塗布線。HC 系列用在顯示器表面，任何微小的灰塵都看得見，所以 CL-01 的潔淨要求比 CL-02 嚴格。從原料進廠到出貨的完整流程，見製程流程概覽（MFG-TRN-003）。

## 5. 為什麼品質這麼重要

- HC 系列貼在客戶的螢幕最外層，**一顆灰塵、一道刮痕都會變成客戶產品的不良**。
- RF 系列撕開的力道如果不對，客戶的膠帶或光學膠在製程中會撕不下來，或者提早脫落，整批都受影響。
- 這兩種問題很多時候用肉眼看不出來，所以公司在進料、生產中、出貨前都設有檢驗，並要求每一卷都能追溯。

## 1. 使用說明

本表只解釋「這個詞是什麼意思」。各項目的數值、標準與作業方法屬於部門文件，請洽負責部門。

「常見口語說法」是現場同仁實際會講的話，方便聽到時知道指的是哪一個詞。

## 2. 材料與產品

| 術語       | 意思                                                       | 常見口語說法             |
| ---------- | ---------------------------------------------------------- | ------------------------ |
| 基材       | 被塗布的原料薄膜，本公司使用透明 PET 膜                    | 底膜、原膜、素膜         |
| 塗液       | 塗在基材上的液體，由樹脂、添加劑與溶劑調成                 | 藥水、膠水、塗料         |
| 硬塗膜     | 表面有耐刮塗層的薄膜（HC 系列）                            | 硬化膜、保護膜           |
| 防眩       | 表面做成細微凹凸，減少反光（HC-230AG）                     | 霧面、AG                 |
| 離型膜     | 表面塗有矽塗層、能讓黏膠輕鬆撕下的薄膜（RF 系列）          | 離型紙、底紙、保護底膜   |
| 母卷       | 塗布線收卷完成的一整大卷產品，是追溯與檢驗的基本單位       | 大卷、整卷               |
| 批號       | 每個母卷唯一的編號，可追溯到產線、日期、班別與原料         | 卷號、Lot                |
| 工單       | 生產指令，記錄要生產什麼產品、多少數量                     | 單子、WO                 |

## 3. 製程

| 術語         | 意思                                                       | 常見口語說法             |
| ------------ | ---------------------------------------------------------- | ------------------------ |
| 卷對卷       | 放卷、加工、收卷連續進行的生產方式                         | Roll to Roll、R2R        |
| 放卷／收卷   | 把整卷材料送進機器／把加工好的膜捲回成卷                   | 上料／下料               |
| 電暈處理     | 用高壓放電處理膜面，讓塗液附著得更好                       | 電暈、打電暈             |
| 狹縫塗布     | 塗液從細長縫隙擠出、塗在膜上的方式（CL-01）                | Slot Die、模頭           |
| 微凹版塗布   | 用表面有細小網穴的滾輪帶起塗液、轉印到膜上（CL-02）        | 凹版、Gravure            |
| 刮刀         | 刮掉滾輪表面多餘塗液的薄金屬片（CL-02）                    | 刀片                     |
| 烘箱         | 用熱風把溶劑烘乾的長形箱體，分成數區                       | 爐子                     |
| UV 固化      | 用紫外線燈照射讓塗層硬化（CL-01）                          | 照 UV、過燈              |
| 線速         | 膜在生產線上前進的速度                                     | 車速                     |
| 換線         | 從生產一種產品切換到另一種產品                             | 換產品、換料             |
| 開機／停機   | 生產線開始運轉／停止運轉                                   | 開車／停車               |
| 試產         | 新產品在量產線上試做，確認能否穩定生產                     | 試機、試做               |

## 4. 品質

| 術語           | 意思                                                       | 常見口語說法                 |
| -------------- | ---------------------------------------------------------- | ---------------------------- |
| IQC            | 進料檢驗：原物料使用前的檢驗                               | 進料                         |
| IPQC           | 製程巡檢：生產過程中的抽樣檢驗                             | 巡檢                         |
| OQC            | 出貨檢驗：產品出貨前的檢驗                                 | 出貨驗                       |
| 首件／首卷檢驗 | 開機或換線後第一卷先送檢，確認條件正確                     | 首件                         |
| 離型力         | 把黏膠從離型膜上撕開所需的力量，RF 系列最重要的特性        | 撕開的力道、好不好撕         |
| 殘餘接著率     | 黏膠接觸過離型膜後還保有多少黏性，用來判斷矽塗層有沒有轉移 | 黏性還剩多少                 |
| 鉛筆硬度       | 用不同硬度的鉛筆劃塗層表面，看會不會刮傷，判斷塗層硬度     | 硬度                         |
| 霧度           | 膜看起來霧霧的程度，亮面產品越低越好                       | 霧不霧                       |
| 透光率         | 光線能穿透膜的比例                                         | 透不透                       |
| 密著性         | 塗層黏在基材上的牢固程度，常用百格測試                     | 會不會掉、百格               |
| 快速篩檢       | 以加速條件量測離型力，比正式量測更快出結果，用於生產中判斷 | 快篩                         |
| 異常代碼       | 外觀與品質異常的分類代碼，D01～D11                         | D 碼                         |
| 條紋           | 塗層上出現的線狀痕跡（D01）                                | 一條一條的、拉線             |
| 異物           | 塗層中夾雜灰塵、纖維或顆粒（D03）                          | 髒點、顆粒、亮點             |
| 收卷不良       | 卷的兩側不整齊或捲得太鬆（D11）                            | 捲歪、伸縮筒、竹筍           |
| 待判／隔離     | 有疑慮的產品先放待判區；確定不良的放隔離區                 | 黃單、紅單                   |
| 特採           | 不完全符合規格，但經評估與客戶同意後例外放行               | 特採                         |
| 客訴           | 客戶對品質的正式抱怨                                       | 客抱                         |
| 8D             | 處理重大問題的八個步驟，找出根本原因並防止再發             | 8D 報告                      |
| Cpk            | 製程能力指標，表示製程穩定落在規格內的程度                 | 製程能力                     |
| 校正           | 定期確認量測儀器準不準                                     | 送校、校機                   |

## 5. 設備與環境

| 術語           | 意思                                                       | 常見口語說法             |
| -------------- | ---------------------------------------------------------- | ------------------------ |
| 潔淨室         | 控制空氣中灰塵數量的生產區域，塗布區都是潔淨室             | 無塵室                   |
| Class          | 潔淨度等級，數字越小越乾淨                                 | 等級                     |
| 風淋           | 進潔淨室前用強風吹掉身上灰塵的小房間                       | 吹風室                   |
| FFU            | 天花板上的送風過濾機組，持續送入乾淨空氣                   | 天花板濾網               |
| HEPA           | 高效率空氣濾網，裝在 FFU 裡                                | 濾網                     |
| 剝離試驗機     | 量測離型力的拉力機                                         | 拉力機                   |
| SDS            | 化學品安全資料表，記載危害與急救方法                       | 物質安全資料表、MSDS     |

## 6. 文件與管理

| 術語       | 意思                                                       |
| ---------- | ---------------------------------------------------------- |
| SOP        | 標準作業程序，規定一件工作一步一步怎麼做                   |
| ECN        | 製程變更通知，製程、原料或設備的永久變更都要經過核准       |
| 現行版本   | 目前有效的文件版本；舊版作廢後不得再使用                   |
| AR 單      | 異常通報單，A 級異常要開立                                 |
| 交接       | 換班時交班者與接班者當面說明線上狀況                       |
| 5S         | 整理、整頓、清掃、清潔、素養，現場管理的基本要求           |
| 核決層級   | 依金額或影響決定由誰核准，L1 到 L4                         |

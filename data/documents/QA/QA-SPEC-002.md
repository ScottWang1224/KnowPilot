## 1. 適用範圍

CL-01 生產的 HC 系列：HC-200、HC-350、HC-230AG。RF 系列請見 QA-SPEC-003，兩者項目完全不同。

## 2. 允收標準

| 項目           | 方法                                         | HC-200        | HC-350        | HC-230AG      |
| -------------- | -------------------------------------------- | ------------- | ------------- | ------------- |
| 塗層乾膜厚度   | LB-TK-01，橫向 5 點                          | 3.0 ± 0.3 µm  | 5.0 ± 0.5 µm  | 4.0 ± 0.4 µm  |
| 鉛筆硬度       | JIS K5600-5-4，750 g，LB-PH-01               | ≥ 2H          | ≥ 3H          | ≥ 2H          |
| 霧度           | LB-HZ-01，3 點平均                           | ≤ 0.8 %       | ≤ 1.0 %       | 25 ± 3 %      |
| 全光線透光率   | LB-HZ-01，3 點平均                           | ≥ 91.0 %      | ≥ 90.5 %      | ≥ 89.0 %      |
| 密著性         | ASTM D3359 百格（1 mm 間距）                 | 5B            | 5B            | 5B            |
| 外觀           | 暗室燈箱目視 + 線上檢測瑕疵地圖              | 依 QA-SPEC-005 | 依 QA-SPEC-005 | 依 QA-SPEC-005 |

## 3. 抽樣

| 項目                    | 抽樣                                         |
| ----------------------- | -------------------------------------------- |
| 厚度、霧度、透光率      | **每卷**，卷尾取左、中、右 3 片              |
| 鉛筆硬度                | **每卷**（2026-07-20 起，原為每工單首卷）    |
| 密著性                  | 每工單第 1 卷與最後 1 卷                     |
| 燈箱外觀                | 每卷外層 1 m²                                |
| 線上檢測瑕疵地圖        | **每卷全長審閱**（2026-05 起）               |

## 4. 量測方法重點

### 4.1 鉛筆硬度

1. 樣品在 23 ± 2 °C、50 ± 5 % RH 調濕 1 小時。
2. 以規定硬度的鉛筆、45° 角、750 g 荷重，劃 5 條，每條 7 mm。
3. 5 條中有 ≥ 4 條無刮痕，判該硬度合格。
4. 規格為 2H 的產品，以 2H 鉛筆測試；不合格時再用 H 鉛筆確認實際等級，記錄於報告。

### 4.2 線上檢測瑕疵地圖審閱

CL01-IN-01 記錄整卷每個瑕疵的位置與大小。OQC 審閱時：

- 有效寬度內 ≥ 100 µm 的異物 → 依 QA-SPEC-005 判 A 級。
- 瑕疵集中於某一段（每 10 m 超過 5 點）→ 該段切除或整卷判定。
- 閾值設定必須為 80 µm；地圖顯示閾值不是 80 µm 時，該卷不得放行，通報 PE。

燈箱目視只能看到外層，**內層的異物只能靠瑕疵地圖發現**，這是 2026-04 異物客訴後加入的項目。

## 5. 放行條件

全部符合才可放行：

1. 第 2 節全部項目合格。
2. 該卷在生產中沒有未結案的異常，或異常已由 QA 判定並處置完成。
3. 首卷送檢（製造部開機與換線時送的樣品）結果合格。
4. 量測儀器在校正有效期內。

放行由品管課課長簽核；特採放行需 QA 經理核准，並經業務確認客戶同意。

## 6. 不合格處理

| 狀況                             | 處理                                         |
| -------------------------------- | -------------------------------------------- |
| 鉛筆硬度不合格                   | 該卷判 A 級（D10），同工單其他卷全數重測     |
| 霧度、透光率、厚度不合格         | 依超出程度判 B 或 A；可切除段由 QA 標示      |
| 密著性 < 5B                      | 工單內所有卷加測密著性                       |
| 外觀 A 級瑕疵                    | 依瑕疵地圖切除或整卷報廢                     |

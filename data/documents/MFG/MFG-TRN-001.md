## 1. 訓練目標

完成本訓練後，學員應能：

1. 正確寫出母卷、塗液、工單與異常通報單的編號。
2. 判斷夜班生產的母卷應該使用哪一天的日期。
3. 依規定更正寫錯的紀錄。

訓練時數 2 小時，完成後由班長以第 6 節練習題確認，答對 4 題以上才算通過。

## 2. 批次紀錄的必填欄位

| 欄位         | 內容                              | 範例               |
| ------------ | --------------------------------- | ------------------ |
| 工單         | WO-年月-序號                      | WO-2607-0153       |
| 產品         | 型號                              | HC-200             |
| 母卷批號     | 見第 3 節                         | C1-260708N-03      |
| 基材品號     | 公司品號                          | BF-P050            |
| 基材批號     | 供應商出貨標籤上的批號，照抄      | （依標籤）         |
| 塗液批號     | CF-年月日-序號                    | CF-260707-02       |
| 設備         | 產線                              | CL-01              |
| 作業者       | 姓名，不可只寫工號                | —                  |
| 開始與結束   | 時間（24 小時制）                 | 23:40 ／ 00:32     |

## 3. 母卷批號規則

格式：**線別代碼-上班日期班別-序號**

| 位置       | 說明                                             |
| ---------- | ------------------------------------------------ |
| 線別代碼   | C1 = CL-01，C2 = CL-02                           |
| 上班日期   | YYMMDD，**以上班日為準**                          |
| 班別       | D = 早班，E = 中班，N = 夜班（直接接在日期後面）  |
| 序號       | 該班該線的第幾卷，每班從 01 起算；試產卷前加 T   |

**夜班日期規則：** 夜班從 23:00 上班到隔天 07:00，整個夜班生產的母卷都用**上班那一天**的日期。

> 例：2026-07-08 23:00 上班的夜班，在 07-09 凌晨 02:30 收完的第 3 卷，批號是 **C1-260708N-03**，不是 C1-260709N-03。

同樣規則適用於塗液批號、異常通報單編號：夜班開的異常通報單也用上班日。

## 4. 填寫原則

1. **即時填寫**：每卷收完 10 分鐘內寫完，不可在下班前一次補寫。
2. 使用黑色或藍色原子筆，不可使用鉛筆或可擦筆。
3. 數字照實際讀值寫，不可四捨五入成規格值。
4. 沒有發生的項目寫「無」，不可空白。

## 5. 更正方式

1. 在錯誤內容上**畫一條橫線**，原內容仍要看得清楚。
2. 在旁邊寫上正確內容、更正日期與簽名。
3. 更正原因寫在備註欄（例如「抄錯批號」）。
4. **禁止**：使用修正液或修正帶、塗黑、撕頁、重新謄寫整頁。
5. 已交出的紀錄需要更正時，找班長一起更正，班長在旁簽名。

## 6. 練習題

1. CL-02 在 2026-08-19 中班生產的第 2 卷，批號是什麼？
2. CL-01 在 2026-07-08 23:00 上班的夜班，07-09 05:10 收完的第 4 卷，批號是什麼？
3. 塗液批號寫成 CF-260707-2，哪裡有問題？
4. 收卷時間抄錯，可以用修正帶蓋掉重寫嗎？
5. CL-01 試產在 2026-09-12 早班生產的第 1 卷，批號是什麼？

**參考答案：**

1. C2-260819E-02
2. C1-260708N-04（夜班用上班日 07-08）
3. 序號要 2 位數，應為 CF-260707-02
4. 不可以。畫一條橫線，旁邊寫正確時間、日期、簽名，備註寫原因
5. C1-260912D-T01

## 7. 常見錯誤

| 錯誤                                   | 後果                                       |
| -------------------------------------- | ------------------------------------------ |
| 夜班過了午夜就改用隔天日期             | 同一班的母卷被拆成兩天，追溯時找不到        |
| 基材批號只寫後 4 碼                    | 客訴時無法對應到供應商批號                 |
| 開始時間在下班前補寫                   | 與設備紀錄對不上，異常調查無法確認時間軸   |

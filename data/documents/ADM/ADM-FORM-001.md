## 1. 填寫位置

請購單在公司 ERP 系統「採購」→「請購單」填寫。紙本請購單自 2025 年起停用。

## 2. 欄位說明

| 欄位           | 必填 | 說明                                                          |
| -------------- | ---- | ------------------------------------------------------------- |
| 請購部門       | 是   | 系統依登入帳號自動帶入                                        |
| 費用歸屬       | 是   | 預算科目；不確定時詢問部門助理                                |
| 品名           | 是   | 原物料與備品請用公司品號（例如 FC-01、DB-15），系統自動帶出規格 |
| 規格           | 是   | 非料號品項：品牌型號以外，寫清楚尺寸、材質、數量單位          |
| 數量、單位     | 是   |                                                               |
| 預估單價       | 是   | 參考上次採購價或網路價格；用於決定核決層級                    |
| 需求日期       | 是   | 實際需要到貨的日期；請預留採購作業時間（一般 2 週）            |
| 用途說明       | 是   | 為什麼需要、用在哪裡                                          |
| 建議供應商     | 否   | 有特定供應商時填寫，並說明原因                                |
| 唯一報價說明   | 條件 | 只有 1 家報價且金額超過 30,000 元時必填                        |
| 急件           | 否   | 勾選時需填「急件原因」                                        |
| 固定資產       | 條件 | 單價 80,000 元以上，系統自動勾選                              |
| 附件           | 否   | 報價單、規格書、圖面                                          |

## 3. 原物料請購

- 只能選擇合格供應商名單內的供應商。
- 數量依生管組排程計算，附上需求計算表。
- 評估中供應商的樣品，請購單選擇「研發樣品」類別，由研發部提出，不可用一般原物料類別。

## 4. 常見退件原因

| 原因                                   | 正確做法                                       |
| -------------------------------------- | ---------------------------------------------- |
| 規格只寫「同上次」                     | 寫完整規格，或用公司品號                       |
| 同一需求拆成多張單                     | 合併成一張，依總金額核決                       |
| 需求日期為今天或明天，但未勾選急件     | 依實際情況勾選急件並說明原因                   |
| 用途說明只寫「生產用」                 | 寫明產線、設備或專案                           |
| 預估單價明顯偏低，造成核決層級錯誤     | 依實際行情填寫                                 |

## 5. 查詢進度

ERP 請購單頁面顯示目前狀態：核准中 → 詢價中 → 採購核准 → 已下單 → 已到貨 → 已驗收。超過需求日期仍未到貨，聯絡採購課（分機 105）。

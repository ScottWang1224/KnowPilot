## 第 1 條 目的

維持現場整齊、物料可追溯，並透過定時巡檢及早發現設備與製程的偏移。

## 第 2 條 定位線顏色

| 顏色 | 用途                           |
| ---- | ------------------------------ |
| 黃   | 走道、試產品專用區、待判區     |
| 綠   | 合格待驗品、成品               |
| 紅   | 不良品、隔離品                 |
| 藍   | 原物料（基材、塗液）           |
| 白   | 工具、清潔用品                 |

物品必須放在對應顏色的區域內，不得壓線或跨區。

## 第 3 條 線邊物料存量上限

| 物料                       | CL-01                  | CL-02                  |
| -------------------------- | ---------------------- | ---------------------- |
| 清潔溶劑                   | CS-02 ≤ 20 L           | CS-03 ≤ 40 L           |
| IPA（CS-01）               | ≤ 5 L                  | ≤ 5 L                  |
| 塗液                       | 當班使用量             | 當批（≤ 8 小時用量）   |
| 基材                       | 當班 + 下一卷          | 當班 + 下一卷          |

溶劑一律放在防爆櫃或加蓋的防爆桶內，使用後立即加蓋。化學品存放規定見 ADM-SOP-002。

## 第 4 條 巡檢

1. 每 **2 小時**巡檢一次，由當班操作員依路線執行，結果寫在「巡檢表」。
2. 巡檢路線：放卷 → 電暈 → 塗布頭 → 烘箱 → （CL-01：UV）→ 冷卻輥 → 檢測 → 收卷。

| 巡檢項目             | CL-01 標準                                  | CL-02 標準                              |
| -------------------- | ------------------------------------------- | --------------------------------------- |
| 烘箱溫度（中段）     | 各區設定值 ± 5 °C                           | 5 區設定值 ± 5 °C                       |
| 加熱器斷線警示燈     | —                                           | 全部不亮                                |
| 過濾器壓差           | FL-01 < 0.15 MPa、FL-02 < 0.20 MPa          | 依濾袋更換時間                          |
| UV 區氧濃度          | 當班產品規定值以內                          | —                                       |
| 塗液可使用時間       | —                                           | 剩餘 ≥ 1 小時                           |
| 收卷端面             | 錯位 < 3 mm                                 | 錯位 < 3 mm                             |
| 線上檢測             | 運轉中、無未處理報警                        | 運轉中、無未處理報警                    |
| 溶劑桶               | 加蓋、存量未超限                            | 加蓋、存量未超限                        |
| FFU                  | 全部運轉                                    | 全部運轉                                |

3. 巡檢發現不符合：能當場改善的當場改善並記錄；不能的，通報班長。
4. 收卷端面錯位 3 mm 以上，依收卷不良 D11 記錄分級。

## 第 5 條 5S 稽核

1. 每月由課長對所轄產線稽核一次，製造部經理每季抽查。
2. 評分項目與配分：

| 項目     | 配分 | 重點                                       |
| -------- | ---- | ------------------------------------------ |
| 整理     | 20   | 現場沒有不需要的物品、過期塗液             |
| 整頓     | 20   | 依定位線放置，標示清楚                     |
| 清掃     | 20   | 設備、地面無塗液殘留與粉塵                 |
| 清潔     | 20   | 清潔紀錄完整、按頻率執行                   |
| 素養     | 20   | 穿著、溶劑加蓋、交接確實                   |

3. **85 分以上**合格；70–84 分需在 1 週內改善並複查；70 分以下由經理約談班長。
4. 連續 3 個月 90 分以上的班別，於季會公開表揚。

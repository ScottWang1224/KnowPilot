## 1. 目的

確保檢驗紀錄完整、可追溯，出貨放行所依據的數據都有原始紀錄可以查證。

## 2. 審閱頻率與負責人

| 紀錄                               | 審閱頻率         | 審閱者           |
| ---------------------------------- | ---------------- | ---------------- |
| IQC 進料檢驗紀錄                   | 每日             | 品管課 課長      |
| IPQC 巡檢紀錄、快速篩檢紀錄        | 每日早班 09:00 前 | 品管課 IPQC 組長 |
| OQC 出貨檢驗紀錄                   | 每批放行前       | 品管課 課長      |
| 實驗室量測原始資料                 | 每週             | 實驗室 主任      |
| 量測儀器校正紀錄                   | 每月             | 實驗室 主任      |

夜班與假日產生的紀錄，於下一個工作日早班審閱。

## 3. 查核項目

1. **識別一致**：母卷批號、樣品編號、工單在各紀錄中一致；夜班批號使用上班日日期。
2. **完整**：日期、時間、儀器編號、量測者、結果都有填寫，沒有空白欄位。
3. **方法版本**：使用的檢驗規範與量測方法是現行版本。
4. **原始資料**：結果可以對應到儀器輸出（剝離試驗機、XRF、霧度計的電子檔或列印）。
5. **儀器有效**：使用的儀器在校正有效期內（見 QA-SOP-004）。
6. **判定正確**：結果與規格比對、分級正確；超出規格的項目有開立異常紀錄。
7. **更正方式**：只能畫一條線更正並簽名註明原因，不可使用修正液或覆寫。

## 4. 發現問題時

| 問題                               | 處理                                                           |
| ---------------------------------- | -------------------------------------------------------------- |
| 欄位漏填、簽名遺漏                 | 退回填寫者 24 小時內補正                                       |
| 結果與原始資料不符                 | 停止該批放行，由實驗室重新確認；確認錯誤者依程序更正           |
| 使用過期儀器                       | 依 QA-SOP-004 評估受影響的量測，必要時重測                     |
| 判定錯誤造成不合格品被放行         | 立即通知 QA 經理，追查已出貨範圍                               |
| 疑似竄改紀錄                       | 保全原件，通報 QA 經理與行政管理部                             |

## 5. 保存年限

| 紀錄                         | 保存年限 | 保存方式                       |
| ---------------------------- | -------- | ------------------------------ |
| IQC 紀錄、供應商 CoA          | 3 年     | 電子檔（文件管理系統）         |
| IPQC、快速篩檢紀錄           | 3 年     | 紙本 1 年後掃描成電子檔        |
| OQC 紀錄、出貨檢驗報告       | 5 年     | 電子檔                         |
| 實驗室原始資料               | 5 年     | 儀器電子檔每月備份             |
| 校正紀錄                     | 儀器報廢後 3 年 | 電子檔                  |
| 8D 報告、客訴紀錄            | 10 年    | 電子檔                         |
| 留樣（每卷出貨樣品）         | 2 年     | 樣品室，溫度 23 ± 5 °C          |

文件與紀錄管理的一般規定見 QA-RULE-002。

## 6. 留樣

- OQC 每卷保留 A4 大小樣品 2 片，標示批號與出貨日。
- 客訴時以留樣比對，不需要等客戶寄回樣品才開始調查。
- 留樣超過保存年限，由實驗室每季整批報廢並記錄。

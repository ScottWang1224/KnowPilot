## 2. 現象

收卷完成後，母卷端面呈望遠鏡狀錯位（內層往驅動側滑出）：

| 卷號            | 完成時間 | 端面錯位 | 等級              |
| --------------- | -------- | -------- | ----------------- |
| C2-260819E-01   | 16:05    | 6 mm     | B                 |
| C2-260819E-02   | 16:52    | 8 mm     | B                 |
| C2-260819E-03   | 17:40    | 9 mm     | B → **升 A 級**   |

每卷錯位都在 3–10 mm 的 B 級範圍內，但同一班 D11 第 3 次 B 級，依規定升為 A 級。

| 時間  | 處置                                                                                 |

| 16:05 | 第 1 卷錯位 6 mm，判 B 級。檢查收卷張力 140 N、錐度 25 %，與當時條件表相符          |
| 16:20 | 通報 QA 值班；端面以保護板固定，移至待判區                                          |

| 17:00 | 電話通知課長張淑芬，說明可能是條件問題                                              |
| 17:40 | 第 3 卷錯位 9 mm，同班第 3 次 B 級 → **升 A 級，17:42 停線**                        |
| 17:50 | 通報課長、QA 值班、PE 周佩珊（18:00 前仍在廠）                                       |
| 18:05 | 開立 AR-260819-01                                                                    |
| 18:10 | PE 到場，確認設備張力控制正常，判斷為收卷條件不足                                   |
| 18:40 | PE 決定暫時措施：線速由 90 m/min 降至 **70 m/min**，張力與錐度不變                   |
| 18:55 | 復機                                                                                 |
| 19:45 | 降速後第 1 卷錯位 2 mm，正常                                                        |

停線時間 73 分鐘。

## 4. 原因（PE 調查）

1. RF 系列的矽離型面摩擦係數很低，層與層之間容易滑動。
2. 75 µm 基材比 50 µm 硬，收卷時外層對內層的壓力不足以壓住內層。
3. 當時 RF-25 收卷錐度 25 %，越往外層張力下降不夠，內層在收卷後期受外層拉扯而向一側滑出。錯位都從約 2,500 m 之後才開始變大，與卷徑變大後外層張力過高的推論一致。

## 5. 處置

| 項目                       | 內容                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| 不良卷                     | 3 卷在 CL-02 以復卷模式（不塗布）重新收卷，端面錯位 < 3 mm，QA 放行   |
| 暫時措施（08-19～08-31）    | RF-25 線速降至 70 m/min                                              |
| 永久對策                   | ECN-2026-014：RF-25 收卷錐度 25 % → 35 %，2026-09-01 生效；線速恢復 90 m/min |
| 流出                       | 無                                                                   |

## 7. 效果確認

ECN 生效後 2026-09-01 至 2026-09-30，RF-25 共生產 86 卷（線速 90 m/min），端面錯位全部 < 3 mm，無 D11 紀錄。

## 8. 心得

單卷都是 B 級時，很容易每卷都「標示後繼續生產」。本案依同班 3 次 B 級升 A 級的規定停線，才讓 PE 在當班就介入。交接時請一定寫明各代碼的 B 級次數（見 MFG-RULE-002）。

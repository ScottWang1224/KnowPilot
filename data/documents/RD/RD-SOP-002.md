## 1. 目的

讓新產品依固定的關卡推進，並在移轉量產時，把 PE、QA、製造部需要的資訊一次交接清楚。

## 2. 階段與關卡

| 階段 | 名稱         | 主要工作                                       | 關卡審查（主持）           | 通過條件                                       |
| ---- | ------------ | ---------------------------------------------- | -------------------------- | ---------------------------------------------- |
| G0   | 概念         | 市場或客戶需求、目標規格、可行性               | 研發部經理                 | 目標規格明確，現有產線可能可以生產             |
| G1   | 實驗室開發   | 配方開發、研發塗布機試作                       | 研發部經理                 | 實驗室樣品達目標規格的主要項目                 |
| G2   | 量產線試產   | 試產代號 NP，在 CL-01／CL-02 試產（通常 3 次） | 廠長                       | 量產線樣品達暫定規格；製程窗口足夠             |
| G3   | 客戶認證     | 送樣、客戶評估                                 | 廠長                       | 客戶認可                                       |
| G4   | 量產移轉     | 正式規格、ECN、教育訓練                        | 廠長                       | PE 判定 Cpk ≥ 1.33，相關文件發行              |

## 3. 試產通知（G1 → G2）

研究員在試產前至少 **2 週**發出試產通知給 PE、製造部、QA，內容：

1. 試產代號（NP-年份-序號，由研發部經理核發）。
2. 目標產品與暫定規格（項目、目標值、量測方法）。
3. 塗液規格：固含量、黏度、可使用時間。
4. 研發試作條件與已知的敏感因子。
5. 試產希望的長度與次數。
6. 試產塗液的數量與交付日期。

試產通知**不含配方組成**。對製造部的排程與標籤，只使用試產代號。

## 4. 試產中研發部的工作

- 派研究員或試作工程師到現場，提供技術指導；參數調整由 PE 決定。
- 依 RD-SOP-001 登錄試產樣品，樣品編號連結試產代號與母卷批號。
- 試產後 5 個工作天內提出試作報告（RD-RPT），包含與實驗室結果的差異分析。

## 5. 技術移轉資料包（G4）

| 內容                                     | 交給       |
| ---------------------------------------- | ---------- |
| 產品規格建議（含量測方法）               | QA、PE     |
| 塗液規格與調配指示單                     | 製造部調配組（依 RD-SEC-001） |
| 製程條件建議與敏感因子分析               | PE         |
| 試產數據彙整（三次試產）                 | PE、QA     |
| 異常經驗（試產中出現的問題與原因）       | PE、製造部 |
| 原料規格與進料檢驗建議                   | QA、採購   |

## 6. 移轉後追蹤

1. 量產最初 3 個工單，研究員每週檢視品質數據。
2. 量產 3 個月內出現的材料面問題，由研發部主導調查。
3. 量產 3 個月後，召開移轉檢討會，結案。

## 1. 目的

在生產過程中及早發現偏移，避免不良品累積到出貨檢驗才被發現。

## 2. 人力配置

| 班別 | QA 在廠人員                                   |
| ---- | --------------------------------------------- |
| 早班 | IPQC 2 人、實驗室 3 人、OQC 2 人               |
| 中班 | IPQC 1 人、實驗室 1 人（18:00 後兼 QA 值班）   |
| 夜班 | **QA 值班 1 人**（IPQC 與實驗室量測一人負責）   |

## 3. CL-01 巡檢項目

| 項目                       | 頻率                         | 標準                                    |
| -------------------------- | ---------------------------- | --------------------------------------- |
| 首卷檢驗（開機、換線）     | 每次                         | 厚度、鉛筆硬度、霧度、透光率             |
| UV 光量紀錄確認            | 每班                         | 製造部量測值在產品規格內                |
| 塗層厚度（離線）           | 每 4 小時                    | 依產品規格                              |
| 線上檢測閾值               | 每班                         | 80 µm                                   |
| 塗布區粒子數抽查           | 每週 2 次                    | ≤ 1,000 顆/ft³                          |
| 換線後霧度（AG 換亮面）    | 換線後第一卷                 | HC-200 ≤ 0.8 %、HC-350 ≤ 1.0 %          |

## 4. CL-02 巡檢項目

| 項目                       | 頻率                         | 標準                                    |
| -------------------------- | ---------------------------- | --------------------------------------- |
| 快速篩檢量測               | **每卷**（製造部取樣後 10 分鐘內送達） | 依 QA-SOP-002 第 5 節判定範圍  |
| 矽塗佈量（XRF）             | 每卷                         | 依產品規格                              |
| 烘箱中段溫度紀錄確認       | 每班                         | 設定值 ± 5 °C                            |
| 線上檢測閾值               | 每班                         | 150 µm                                  |
| 塗布區粒子數抽查           | 每週 1 次                    | ≤ 10,000 顆/ft³                         |

## 5. 快速篩檢的量測責任

1. 製造部每卷取樣送 QA；QA 收樣時記錄收樣時間。
2. QA 依 QA-SOP-002 第 5 節量測，取樣後約 90 分鐘回報結果給班長。
3. 結果 B 級或 A 級：QA 立即電話通知班長，並在快速篩檢紀錄標記。
4. 同一班 D09 第 3 次 B 級：QA 主動提醒班長依規定升 A 級停線。

## 6. 夜班 QA 值班的優先順序

夜班只有 1 位 QA，同時有多件工作時依此順序：

1. A 級異常的判定與通報。
2. CL-02 快速篩檢（影響是否停線）。
3. 首卷檢驗。
4. 其他巡檢與量測。

無法在時限內完成的工作，記錄在 QA 交接表，由早班優先處理。

## 7. 巡檢發現異常

依 QA-SPEC-005 判定異常代碼與等級，通知當班班長；A 級時另通知 QA 課長（夜間以電話）。

## 1. 分工

| 項目                         | 負責                     |
| ---------------------------- | ------------------------ |
| 專業訓練內容（SOP、技能檢定） | 各部門                   |
| 訓練計畫彙整、開班行政、紀錄 | 行政管理部人資課         |
| 法定安全衛生訓練             | 行政管理部環安衛         |

## 2. 年度訓練計畫

1. 每年 11 月，各部門提出下一年度訓練需求（內訓課程、外訓、預算）。
2. 人資課彙整成年度訓練計畫，12 月由總經理核准。
3. 年度訓練預算 2026 年為每人平均 6,000 元，由人資課統一管理。

## 3. 內訓開班

1. 開課部門於開課前 2 週通知人資課：課程名稱、講師、時數、對象、地點。
2. 人資課在教育訓練系統開班並通知學員；學員由主管確認後報名。
3. 上課當天簽到（系統掃碼），缺席需事先請假，無故缺席 2 次通知主管。
4. 課後 3 個工作天內，講師上傳測驗成績；人資課登錄訓練紀錄。
5. 內部講師鐘點費：每小時 800 元（上班時間授課亦同）。

## 4. 外訓

| 項目           | 規定                                                              |
| -------------- | ----------------------------------------------------------------- |
| 申請           | 開課 2 週前填寫外訓申請單，說明與工作的關係                       |
| 核准           | 費用 10,000 元以下：部門經理；以上：廠長                          |
| 補助           | 全額由公司支付；訓練時間視同上班                                  |
| 服務年限       | 單次費用 30,000 元以上，簽訂服務約定：每 30,000 元服務 6 個月；未滿期離職依比例返還 |
| 心得與分享     | 結訓後 1 週內繳交心得；費用 30,000 元以上需在部門內分享            |

## 5. 法定訓練追蹤

| 訓練                             | 對象                       | 頻率             |
| -------------------------------- | -------------------------- | ---------------- |
| 一般安全衛生教育訓練             | 新進員工                   | 到職時 3 小時    |
| 危害性化學品通識                 | 接觸化學品的人員（製造、PE、QA、RD） | 每 3 年複訓 3 小時 |
| 有機溶劑作業主管                 | 製造部課長、組長           | 依法定期間複訓   |
| 防火管理人                       | 環安衛管理師               | 每 3 年複訓      |
| 急救人員                         | 各班至少 1 人              | 每 3 年複訓      |

人資課每月產生到期清單，通知當事人與主管；逾期未完成者暫停相關作業資格（例如化學品作業）。

## 6. 訓練紀錄

1. 教育訓練系統保存每人的訓練紀錄（課程、時數、成績），員工可自行查詢。
2. 技能檢定紀錄由製造部保管正本，副本交人資課登錄。
3. 訓練紀錄保存至員工離職後 5 年。

## 1. 適用範圍

所有使用、搬運、存放化學品的人員，以及進入化學品作業區域的人員（含訪客與承攬商）。

## 2. 廠內主要化學品

| 品名                  | 公司品號         | 主要使用           | 主要危害                       |
| --------------------- | ---------------- | ------------------ | ------------------------------ |
| 甲基乙基酮（MEK）      | RM-S01、CS-02    | HC 塗液、CL-01 清潔 | 高度易燃、刺激眼睛、蒸氣致暈   |
| 丙二醇甲醚（PGME）     | RM-S02           | HC 塗液            | 易燃                           |
| 正庚烷                | RM-S03、CS-03    | RF 塗液、CL-02 清潔 | 高度易燃、吸入有害、水生毒性   |
| 異丙醇（IPA）          | CS-01            | 擦拭清潔           | 易燃、刺激眼睛                 |
| UV 硬化樹脂與單體      | RM-A01、RM-A02   | HC 塗液            | 皮膚過敏                       |
| 白金觸媒              | RM-CT01          | RF 塗液            | 皮膚與呼吸道過敏               |

正庚烷與 MEK 的閃火點都低於室溫，**任何火源都可能引燃**。

## 3. 標示

1. 所有化學品容器（含分裝的小瓶、噴瓶）必須貼危害標示：品名、危害圖示、警示語、主要危害。
2. 分裝容器沒有標示，發現者應通知主管，內容不明的容器不得使用。

## 4. 安全資料表（SDS）

1. 每項化學品都有中文 SDS，由環安衛管理，每 3 年或供應商更新時檢討。
2. 查閱方式：
   - 現場：調配室 A、B 與各線控制台旁的 SDS 資料夾。
   - 電子：公司文件系統「環安衛／SDS」。
3. SDS 第 4 節（急救措施）、第 5 節（滅火措施）、第 6 節（洩漏處理）、第 8 節（個人防護）是現場最常用的部分。

## 5. 存放

| 地點                       | 規定                                                        |
| -------------------------- | ----------------------------------------------------------- |
| 溶劑倉庫                   | 防爆、獨立建築；總量依消防法規核定量                        |
| 調配室 A、B                 | 只放當日使用量；防爆櫃存放                                  |
| 產線線邊                   | 依製造部規定的上限（CL-01、CL-02 不同），使用後立即加蓋     |
| 實驗室                     | 防爆櫃，單一品項 ≤ 4 L                                       |
| 辦公室                     | 禁止存放溶劑                                                |

- 氧化劑與溶劑分開存放。
- 防爆櫃門保持關閉。

## 6. 個人防護具

| 作業                         | 防護具                                         |
| ---------------------------- | ---------------------------------------------- |
| 溶劑擦拭、塗布頭清潔         | 丁腈防溶劑手套、護目鏡、活性碳口罩             |
| 調配（投料、攪拌）            | 丁腈手套、護目鏡、活性碳口罩、防靜電工作服     |
| 搬運溶劑桶                   | 丁腈手套、安全鞋                               |
| 處理洩漏                     | 丁腈手套、護目鏡、全面罩（有機蒸氣濾罐）       |

活性碳口罩濾罐每 8 小時使用時間或聞到溶劑味時更換。

## 7. 廢液與廢棄物

| 類別                 | 容器               | 處理                                    |
| -------------------- | ------------------ | --------------------------------------- |
| 廢溶劑               | 紅色防爆廢液桶     | 滿 80 % 時通知環安衛，委託合格廠商清運   |
| 含溶劑的擦拭布       | 有蓋金屬桶         | 每班清空至廢棄物暫存區                  |
| 過期或報廢塗液       | 原容器，貼「報廢」 | 交環安衛統一處理                        |

不同溶劑的廢液可以混合（都是可燃性有機溶劑），但**不可與水性廢液或酸鹼混合**。

## 8. 訓練

接觸化學品的人員須完成危害性化學品通識訓練（3 小時），每 3 年複訓。

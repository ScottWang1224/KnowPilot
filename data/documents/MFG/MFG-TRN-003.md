## 1. 整體流程

| 順序 | 站點               | 在做什麼                                               | 負責部門                         |
| ---- | ------------------ | ------------------------------------------------------ | -------------------------------- |
| 1    | 原料進廠           | 基材、樹脂、溶劑等原物料到貨，倉庫點收數量             | 製造部生管組（倉庫）             |
| 2    | 進料檢驗（IQC）    | 確認原物料符合規格，合格才能使用                       | 品質保證部                       |
| 3    | 塗液調配           | 依研發部提供的調配指示，把原料調成塗布用的液體         | 製造部調配組                     |
| 4    | 塗布生產           | 在 CL-01 或 CL-02 上把塗液塗在基材上，烘乾、固化、收卷 | 製造部（操作）、製程工程部（條件） |
| 5    | 製程巡檢（IPQC）   | 生產過程中抽樣量測，及早發現異常                       | 品質保證部                       |
| 6    | 出貨檢驗（OQC）    | 每一卷出貨前檢驗，合格才放行                           | 品質保證部                       |
| 7    | 包裝與出貨         | 依訂單包裝、安排出貨                                   | 製造部生管組；交期由業務課聯繫   |
| 8    | 客戶回饋           | 客戶的品質抱怨由品質保證部受理與調查                   | 品質保證部                       |

支援單位：
- **製程工程部**：訂定每個產品的製程條件、處理製程異常、設備保養（設備課）。
- **研發部**：新產品開發、配方管理；新產品要先在產線上試產，確認可以穩定生產後才移轉量產。
- **行政管理部**：採購、人資、資訊、環安衛。

## 2. 塗布線內部的工序

兩條線的工序大致相同，差別在塗布方式與固化方式：

| 工序       | 做什麼                                           | CL-01（HC 系列）       | CL-02（RF 系列）        |
| ---------- | ------------------------------------------------ | ---------------------- | ----------------------- |
| 放卷       | 把整卷基材裝上機器，連續送出                     | 有                     | 有                      |
| 電暈處理   | 用放電處理基材表面，讓塗液更容易附著             | 有                     | 有                      |
| 塗布       | 把塗液均勻塗在基材上                             | 狹縫塗布頭             | 微凹版塗布頭            |
| 乾燥       | 熱風烘箱把溶劑烘乾                               | 3 區烘箱               | 5 區烘箱                |
| 固化       | 讓塗層硬化成型                                   | UV 燈照射固化          | 烘箱加熱固化            |
| 冷卻       | 冷卻輥降溫                                       | 有                     | 有                      |
| 線上檢測   | 相機全程掃描，自動記錄瑕疵位置                   | 有                     | 有                      |
| 收卷       | 塗好的膜捲成一大卷，稱為「母卷」                 | 有                     | 有                      |

每一個母卷都有唯一的批號，從批號可以追溯到生產日期、班別、產線，以及使用的原料批號。

## 3. 為什麼要分這麼多站

- **進料就擋下問題**：基材或原料有問題，塗布後才發現會浪費整卷產品。
- **生產中就發現偏移**：塗布是連續生產，一卷要生產好一段時間，異常越晚發現，不良品越多。
- **出貨前最後把關**：部分特性（例如離型膜撕開的力道）要放置一段時間後量測才準，所以出貨前一定要等檢驗結果。

## 4. 誰可以在哪一站做什麼

- 生產線的操作由取得技能資格的製造部人員執行，其他部門人員進入塗布區依潔淨室進出管理規範（MFG-RULE-001）辦理。
- 製程條件只有製程工程部可以修改，現場不得自行調整。
- 異常發生時，任何人都要依品質異常通報與批次追溯總則（QA-RULE-001）通報。

各站的作業步驟、條件與檢查標準屬於各部門的作業文件，詳細內容請洽負責部門。

本文件為虛構企業展示資料，內容與數值不得用於真實生產。

## 1. 適用範圍

- 產品：HC-230AG 防眩硬塗膜，基材 BF-P075。主要客戶：客戶 A。
- 產線：CL-01。

## 2. 產品品質目標

| 項目         | 規格         |
| ------------ | ------------ |
| 塗層乾膜厚度 | 4.0 ± 0.4 µm |
| 鉛筆硬度     | ≥ 2H         |
| 霧度         | 25 ± 3 %     |
| 全光線透光率 | ≥ 89.0 %     |
| 密著性       | 5B           |

## 3. 防眩原理與控制重點

HC-230AG 的霧度來自塗液中的 3 µm 有機微粒（RM-F01）。乾燥時溶劑揮發、塗層變薄，微粒頂起塗層表面形成凹凸。霧度主要受三件事影響：

1. **第 1 區乾燥速度**：太快（溫度高）會讓表面先結皮，微粒來不及浮到表面，霧度偏低；所以第 1 區設 55 °C，比 HC-200 低 5 °C。
2. **塗層厚度**：越厚，微粒被埋得越深，霧度越低。厚度每增加 0.2 µm，霧度約下降 1 %。
3. **微粒分散**：微粒會沉降。供液桶必須持續攪拌（60 rpm），停止攪拌超過 30 分鐘的塗液，要重新攪拌 15 分鐘並由調配組確認後才能使用。

## 5. 霧度偏離時的調整（PE 執行）

| 霧度         | 可能原因                         | 調整方向（在上下限內）                  |
| ------------ | -------------------------------- | --------------------------------------- |
| < 22 %       | 第 1 區太熱；塗層太厚；微粒沉降  | 第 1 區降 2 °C；流量降 2 %；確認攪拌     |
| > 28 %       | 塗層太薄；固含量偏高             | 流量升 2 %；請調配組確認固含量           |

每次調整後至少生產 100 m，再請 QA 量測霧度。調整超出上下限時依 PE-RULE-001 開立 ECN。

## 6. 換線注意

HC-230AG 換回亮面產品（HC-200、HC-350）時，殘留微粒會讓亮面產品霧度超標，必須拆解清潔塗布頭並更換兩支濾芯，作業內容見 MFG-SOP-005。

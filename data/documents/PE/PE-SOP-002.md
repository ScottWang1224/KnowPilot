## 1. 目的

客訴由 QA 統一受理與對外回覆。PE 負責回答「**製程上發生了什麼**」：生產當時的條件是否正常、異常從何時開始、影響範圍有多大。

## 2. 時限

| 階段                         | 時限                         |
| ---------------------------- | ---------------------------- |
| QA 轉交客訴單（CC 單）       | —                            |
| PE 完成資料調閱、回報初判    | **24 小時內**                |
| 回覆製程面調查結果           | **3 個工作天內**             |
| 參與 8D 對策與效果確認       | 依 QA 8D 時程                |

## 3. 追查步驟

### 步驟 1：確認客訴批號

從 CC 單取得客訴母卷批號，換算生產日期、班別、產線（批號規則：線別-上班日期班別-序號）。注意夜班批號的日期是上班日，實際生產時間可能是隔天凌晨。

### 步驟 2：調閱資料

| 資料                         | 來源              | 重點                                     |
| ---------------------------- | ----------------- | ---------------------------------------- |
| 設備趨勢紀錄                 | CL-01／CL-02 控制系統 | 烘箱各區溫度、線速、張力、UV 光量、氧濃度 |
| 開機檢查表、巡檢表           | 製造部            | 當班檢查結果與時間                       |
| 交接簿、異常紀錄             | 製造部            | 當班與前後班的異常                       |
| 快速篩檢、IPQC 紀錄          | QA                | 同批與前後卷的量測值                     |
| 塗液調配紀錄                 | 製造部調配組      | 塗液批號、固含量、黏度、觸媒添加時間     |
| 原物料批號                   | 批次紀錄          | 基材、樹脂、矽樹脂批號                   |
| 保養紀錄                     | 設備課            | 前後 1 個月的保養與維修                  |

### 步驟 3：比對

1. 把客訴卷與**同工單其他卷**、**前後工單**的資料放在一起比較，找出客訴卷不同的地方。
2. 找出異常開始與結束的時間點，據此推定影響範圍（哪些卷號）。
3. 列出所有可能原因，逐一以資料排除。

### 步驟 4：初判回報（24 小時內）

以電子郵件回報 QA：可能原因、影響卷號範圍、建議的圍堵措施（例如庫存與在途品的隔離範圍）。

### 步驟 5：調查結果（3 個工作天內）

書面回覆，內容包括：根本原因（含為何發生、為何沒有被發現）、證據、建議的永久對策（若需要變更規格，依 PE-RULE-001 開立 ECN）。

## 4. 實例：CC-2026-003 RF-25 離型力偏高

| 項目       | 內容                                                         |
| ---------- | ------------------------------------------------------------ |
| 客訴       | 客戶 C，2026-02-13 反映 RF-25 離型力 38 g/25mm（規格 20–30）  |
| 客訴批號   | C2-260209D-02～04（工單 WO-2602-0031，共 01～04 四卷）         |
| PE 初判    | 2026-02-14（24 小時內）                                      |

**調閱與比對發現：**

1. CL02-OV-03 控制器顯示溫度全程 145 °C，看起來正常。
2. 但加熱器電流紀錄顯示 02-09 **07:52** 起第 3 區電流下降約 1/3，此時第 01 卷剛收完。
3. 以入口與出口熱電偶推算，第 3 區區內實際溫度約 128 °C。原因是 3 支加熱器中 1 支燒斷，而控制用熱電偶裝在加熱器出口，那裡溫度仍維持設定值。
4. 第 01 卷（07:05–07:50）在故障前生產；02～04 卷（07:52–10:05）全部在故障後生產。
5. 10:05 該工單結束，換線生產 RF-12（12:35 開機）。RF-12 第一卷 14:45 快速篩檢結果 19 g/25mm，超出 A 級界限，14:50 停線。PE 檢查烘箱，15:40 量測加熱器電流查出斷線，17:00 更換完成。

**影響範圍：** RF-25 的 02～04 卷（已全部出貨，即客訴批號），以及 RF-12 換線後第 01、02 卷（在廠內，隔離後報廢）。當時 RF-12 停線，是因為換線後第一卷一定做快速篩檢；RF-25 工單中途沒有抽到故障後的卷。

**為何沒有被發現（製程面）：** 控制熱電偶位置不當；沒有加熱器斷線警報。快速篩檢與出貨檢驗的抽樣問題由 QA 在 8D 中說明。

**PE 提出的永久對策：**

1. 控制熱電偶改為中段（2026-03-07～08 停機施工）。
2. 每區加裝加熱器斷線警報。
3. 每月量測加熱器電流（PE-PLAN-001）。

研發部另外從材料面提出配方修訂（ECN-2026-009），由研發部說明。

## 5. 注意事項

- PE **不直接與客戶聯繫**，所有對外說明經 QA。
- 調閱的設備趨勢資料要另存一份，附在調查結果中，避免日後被系統自動清除（控制系統保存 6 個月）。

本文件為虛構企業展示資料，內容與數值不得用於真實生產。

為準備 2027 年 3 月的 ISO 9001 證書重新驗證，品質保證部與人資課合辦內部稽核員訓練。

| 項目     | 內容                                       |
| -------- | ------------------------------------------ |
| 日期     | 2026-11-05（四）、11-06（五），08:30–17:30 |
| 時數     | 14 小時                                    |
| 講師     | 外部顧問                                   |
| 名額     | 20 人（每部門至少 2 人）                   |
| 對象     | 主任、課長、組長及工程師以上               |
| 報名     | 教育訓練系統，**10 月 20 日截止**           |

- 結訓測驗 70 分以上取得內部稽核員資格，並列入 2027 年內部稽核小組。
- 訓練時間視同上班；輪班同仁請先與主管確認排班。

聯絡人：人資課（分機 102）。

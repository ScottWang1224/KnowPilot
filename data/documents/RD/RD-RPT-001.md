## 1. 背景

2025-11-18 HC-200 連續條紋事件的直接原因是二次過濾器濾芯破損，膠粒通過後卡在模唇。QA 與 PE 已處理設備面對策。研發部要回答的是：**塗液中的膠粒從哪裡來？配方能不能讓塗液比較不容易產生條紋？**

## 2. 膠粒來源調查

### 2.1 方法

以 FM-HC-021 R4 為基礎，在研發部實驗室調配 2 L 小批，以 5 µm 濾膜過濾後秤量濾膜上的殘留凝膠。

### 2.2 結果

| 條件                                         | 凝膠殘留（mg／L） |
| -------------------------------------------- | ---------------- |
| 標準調配（RM-A01 進料 2 個月內，攪拌溫度 30 °C） | 0.8              |
| RM-A01 進料後 7 個月                         | 4.6              |
| RM-A01 進料後 10 個月                        | 9.3              |
| 攪拌溫度 45 °C（高剪切造成升溫）              | 3.1              |
| 光起始劑 RM-P01 先溶解後加入（標準）          | 0.8              |
| 光起始劑粉末直接加入                         | 2.2              |

事件當時使用的 RM-A01 批號已進料 **8 個月**，推估凝膠量約為新料的 6 倍。

### 2.3 結論

1. RM-A01（聚氨酯丙烯酸寡聚物）存放超過 6 個月，會逐漸產生微凝膠。
2. 調配時溫度超過 40 °C 也會產生凝膠。
3. 光起始劑必須先以溶劑溶解再加入。

## 3. 配方因素對條紋的影響

以研發塗布機（狹縫塗布，模擬 CL-01 條件）塗布 HC-200 配方，改變單一因子，以條紋出現前的最大塗布速度（臨界速度）評估塗布穩定性，數值越高越不容易出現條紋。

| 因子                | 條件                 | 臨界速度（m/min） | 備註                          |
| ------------------- | -------------------- | ----------------- | ----------------------------- |
| 標準                | FM-HC-021 R4          | 31                |                               |
| 調平劑 RM-L01       | 0.3 %                | 26                | 邊緣出現縮邊                  |
| 調平劑 RM-L01       | 0.8 %                | 32                | 霧度上升 0.2 %，不採用         |
| 溶劑 MEK／PGME       | 80／20                | 24                | 乾燥太快，模唇易乾涸          |
| 溶劑 MEK／PGME       | 60／40                | 33                | 乾燥負荷增加，需評估烘箱      |
| 黏度                | 10 cP（固含量 38 %）  | 27                | 塗布珠不穩定                  |
| 黏度                | 14 cP（固含量 42 %）  | 33                | 厚度需重新計算                |

現行 CL-01 的 HC-200 線速為 20 m/min，與臨界速度有約 50 % 的餘裕，**配方不是條紋的主因**；但 MEK 比例偏高會讓模唇容易乾涸，停機時要特別注意。

## 4. 建議

| 建議                                                     | 對象        | 狀態                         |
| -------------------------------------------------------- | ----------- | ---------------------------- |
| RM-A01 保存期限訂為進料後 6 個月                          | QA、採購    | 2026-03 起納入進料管理        |
| 調配槽 MX-01 攪拌溫度 ≤ 35 °C，加裝溫度顯示               | 製造部調配組 | 2026-03 完成                  |
| 光起始劑先溶解再加入，寫入調配指示單                     | 調配組      | 2026-02 完成                  |
| HC-200 溶劑比例維持 70／30，暫不修改                      | —           | 結論                         |
| 下一版 HC 配方開發時，評估 MEK／PGME 65／35                | 江雅雯      | 待 HC-400 開發一併評估        |

## 5. 未解決問題

研發塗布機與 CL-01 的塗布頭尺寸不同，臨界速度只能作為相對比較，不能直接換算 CL-01 的數值。

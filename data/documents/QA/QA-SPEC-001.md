## 1. 適用範圍

所有進入生產使用的原物料。只接受**合格供應商名單**上的供應商（供應商評鑑由行政管理部採購課與 QA 共同辦理）。評估中的候選供應商物料，只能以研發樣品方式進料，不經本規範放行到產線。

## 2. 一般規定

1. 每批進料都要附供應商出貨檢驗報告（CoA）；沒有 CoA 不收貨。
2. IQC 在收貨後 **2 個工作天內**完成檢驗。
3. 待驗物料放在倉庫藍色待驗區，貼黃色「待驗」標籤；合格改貼綠色標籤，不合格移到紅色區。
4. 生產急用時可申請「緊急放行」，需 QA 經理核准，並在 2 個工作天內補完檢驗；不合格時已投產品依異常處理。

## 3. PET 基材

| 項目               | 方法                           | 抽樣                   | 允收                         |
| ------------------ | ------------------------------ | ---------------------- | ---------------------------- |
| 品號、批號、數量   | 核對標籤與 CoA                 | 每批全數               | 一致                         |
| 外包裝             | 目視                           | 每批全數               | 無破損、無受潮               |
| 厚度               | 測微計，5 點                   | 每批 1 卷              | 標稱值 ± 3 %                  |
| 霧度               | LB-HZ-01                       | 每批 1 卷              | ≤ 0.6 %                      |
| 全光線透光率       | LB-HZ-01                       | 每批 1 卷              | ≥ 89.5 %                     |
| 表面張力（塗布面） | LB-DY-01                       | 每批 1 卷              | ≥ 42 dyn/cm（電暈前）         |
| 外觀               | 燈箱，外層 2 m                 | 每批 1 卷              | 無凝膠點 ≥ 100 µm、無刮傷    |

適用品號：BF-P050、BF-P075（供應商 V01）、BF-P125（供應商 V02）。

| ------- | -------------------------------- | ---------------------------- | ---------- |

| RM-P01  | 外觀、CoA 純度                    | 淡黃色粉末，純度 ≥ 99 %      | 每批       |
| RM-L01  | CoA 核對                         | —                            | 每批       |
| RM-F01  | 粒徑（CoA）、外觀                 | 平均粒徑 3.0 ± 0.3 µm         | 每批       |

## 5. RF 塗液原料

| 品號     | 檢驗項目                                   | 允收                              | 抽樣 |
| -------- | ------------------------------------------ | --------------------------------- | ---- |
| RM-SI01  | 黏度、CoA 乙烯基含量                        | 依品號規格                        | 每批 |
| RM-SI02  | CoA 含氫量                                  | 依品號規格                        | 每批 |
| RM-SI03  | CoA 核對                                    | —                                 | 每批 |

## 6. 溶劑

| 品號            | 項目                     | 允收                   |
| --------------- | ------------------------ | ---------------------- |
| RM-S01、CS-02   | 純度（CoA）、水分        | ≥ 99.5 %、≤ 0.05 %     |
| RM-S02          | 純度（CoA）、水分        | ≥ 99.5 %、≤ 0.05 %     |
| RM-S03、CS-03   | 純度（CoA）              | ≥ 99 %                 |
| CS-01           | 純度（CoA）              | ≥ 99.7 %               |

溶劑每批核對 CoA，每季抽 1 批送外部實驗室驗證。

## 7. 測試膠帶 TP-01

離型力量測結果直接受測試膠帶影響，因此 TP-01 每批進料都要**比對**：

1. 以 QA 保存的標準離型膜，用新批與現用批 TP-01 各量測 5 次離型力。
2. 兩批平均值差異 ≤ 10 % 才允收。
3. 允收後在膠帶捲上標示啟用日期，舊批用完才啟用新批，不可混用。

## 8. 不合格處理

1. 開立「進料不合格通知」，通知採購課與供應商。
2. 處置方式：退貨（預設）、特採（需 QA 經理與使用部門經理同意，限不影響產品規格者）。
3. 同一供應商 3 個月內不合格 2 批以上，通知採購課啟動供應商稽核。

## 1. 適用範圍

CL-02 生產的 RF 系列：RF-12、RF-25、RF-50。HC 系列請見 QA-SPEC-002。

RF 系列的關鍵特性（離型力、殘餘接著率）**無法目視判斷**，必須量測；出貨放行至少要等 20 小時量測結果。

## 2. 允收標準

| 項目                   | 方法                       | RF-12              | RF-25              | RF-50              |
| ---------------------- | -------------------------- | ------------------ | ------------------ | ------------------ |
| 矽塗佈量               | LB-XF-01，3 點平均          | 0.10 ± 0.02 g/m²   | 0.12 ± 0.02 g/m²   | 0.15 ± 0.03 g/m²   |
| 離型力（20 小時）       | QA-SOP-002 第 4 節          | 8–16 g/25mm        | 20–30 g/25mm       | 42–58 g/25mm       |
| 殘餘接著率             | QA-SOP-002 第 6 節          | ≥ 85 %             | ≥ 85 %             | ≥ 85 %             |
| 擦拭脫落               | QA-SOP-002 第 7 節          | 無脫落             | 無脫落             | 無脫落             |
| 外觀                   | 燈箱 + 線上檢測瑕疵地圖     | 依 QA-SPEC-005     | 依 QA-SPEC-005     | 依 QA-SPEC-005     |

## 3. 抽樣（2026-03-10 起）

| 項目                         | 抽樣                                   |
| ---------------------------- | -------------------------------------- |
| 矽塗佈量                     | **每卷**，卷尾左、中、右                |
| 離型力、殘餘接著率（20 小時） | **每卷**（原為每工單首卷）               |
| 擦拭脫落                     | 每卷                                   |
| 外觀、瑕疵地圖               | 每卷                                   |

快速篩檢（70 °C 加速 1 小時）是製造部停線判定用，**不能作為出貨判定**；即使快速篩檢合格，仍要 20 小時量測合格才能放行。

## 4. 20 小時離型力的分級

| 產品  | 允收範圍       | B 級（超出 20 % 以內）    | A 級（超出 20 % 以上） |
| ----- | -------------- | ------------------------- | ---------------------- |
| RF-12 | 8–16 g/25mm    | 6.4–8 或 16–19.2          | < 6.4 或 > 19.2        |
| RF-25 | 20–30 g/25mm   | 16–20 或 30–36            | < 16 或 > 36           |
| RF-50 | 42–58 g/25mm   | 33.6–42 或 58–69.6        | < 33.6 或 > 69.6       |

- 殘餘接著率 < 85 %：不論離型力為何，一律 A 級。
- A 級：整卷不得出貨。
- B 級：不得以一般品出貨；QA 經理評估後可特採（需客戶書面同意）或降級為內部用途。

## 5. 放行條件

1. 第 2 節全部項目合格。
2. 該卷的快速篩檢沒有 B 級或 A 級紀錄；若有，需該卷 20 小時量測合格並由 QA 課長確認。
3. 生產中沒有未結案的異常。
4. 量測儀器與測試膠帶 TP-01 在有效期內。

## 6. 不合格處理

| 狀況                                     | 處理                                                       |
| ---------------------------------------- | ---------------------------------------------------------- |
| 單卷離型力 A 級                          | 同工單前後卷全數加測；通知 PE 調查                          |
| 同工單 2 卷以上 B 級                     | 視同製程偏移，通知 PE；工單其他卷待判                      |
| 矽塗佈量超出規格                         | 依偏離程度判定；連續 2 卷超出通知 PE                        |
| 擦拭脫落                                 | 固化不足，A 級；同工單全數待判                             |

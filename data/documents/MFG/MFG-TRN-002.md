## 1. 目的

確保每項作業都由具備相應能力的人執行。技能檢定**分線認證**：CL-01 與 CL-02 的設備與異常型態不同，取得一條線的資格不代表可以操作另一條線。

## 2. 等級與可執行作業

| -------------------------------------- | ---- | ---- | ---- |
| 放卷、收卷、接紙、貼標籤               | ✔    | ✔    | ✔    |
| 取樣（含 CL-02 快速篩檢取樣）          | ✔    | ✔    | ✔    |
| 潔淨室清潔、粒子量測                   | ✔    | ✔    | ✔    |

| 條紋插片清理（CL-01）、刮刀更換（CL-02）|      | ✔    | ✔    |

| 試產主操作                             |      |      | ✔    |
| 擔任新人帶訓員                         |      |      | ✔    |

## 3. 取得資格的條件

| 等級 | 年資條件                         | 訓練                                         | 考核                                            |
| ---- | -------------------------------- | -------------------------------------------- | ----------------------------------------------- |
| 一級 | 完成新進訓練                     | 該線現場訓練 40 小時，含 MFG-TRN-001         | 帶訓員現場確認 10 項基本動作                    |
| 二級 | 取得一級後在該線工作滿 6 個月    | 該線開機、換線、停機、清潔 SOP 課程 16 小時  | 筆試 80 分以上 + 實作（獨立完成 1 次換線）       |
| 三級 | 取得二級後在該線工作滿 18 個月   | 異常處置課程 12 小時（D01、D03、D09／D10、D11）| 筆試 85 分以上 + 異常處置情境演練 + 課長面談    |

## 4. 考核內容（依產線）

### CL-01

- 筆試：UV 光量與氧濃度規定、濾芯更換基準、各 HC 產品的墊片與線速、換線順序原則。
- 實作：拆解清潔後的組裝扭力確認、插片清理、UV 光量量測。
- 三級情境：首卷硬度不足、過濾器壓差驟降、連續條紋。

### CL-02

- 筆試：快速篩檢判定範圍、塗液可使用時間、各 RF 產品的凹版輥與輥速比、換線沖洗次數。
- 實作：凹版輥拆裝與偏擺量測、刮刀更換、快速篩檢取樣。
- 三級情境：快速篩檢 A 級停線、加熱器斷線、收卷望遠鏡狀錯位。

## 5. 資格維持與失效

1. 資格有效期 **2 年**，到期前 1 個月內完成複訓與筆試（70 分以上）即可展延。
2. 連續 **6 個月**未在該線工作，資格暫停；回到該線後需在三級人員監督下工作 2 週，再由課長確認恢復。
3. 因違反 SOP 造成 A 級異常，資格降一級，3 個月後可重新考核。

## 6. 帶訓員

1. 由三級人員擔任，每位帶訓員同時最多帶 2 名新人。
2. 帶訓期間新人的操作，由帶訓員簽名負責。

## 7. 紀錄

- 技能檢定紀錄卡：每位操作員一張，記錄各線等級、取得日期、到期日。由塗布一課、塗布二課分別保管，副本交行政管理部人資課。
- 班長每月初確認當月排班中，每班每線至少有 1 名三級人員。

## 1. 目的

製造部依 MFG-SOP-009 完成初步處置（插片清理、刮刀更換）後條紋仍存在時，由 PE 依本指引排查與調整參數。

## 2. 排查順序（兩條線共通）

先排除**硬體與物料**，最後才動**參數**。調參數只能改善塗布珠或轉移的穩定性，無法解決模唇缺口或濾芯破損。

1. 確認條紋特徵：位置是否固定、寬度、連續或間歇、是否兩條線同時出現。
2. 確認製造部已完成的處置與結果。
3. 硬體：CL-01 模唇刃口、濾芯；CL-02 刮刀、凹版輥網穴與表面。
4. 物料：塗液黏度、固含量、是否有凝膠或氣泡；同批塗液在另一時段是否正常。
5. 參數：依第 3、4 節範圍調整。

## 3. CL-01（狹縫塗布）

### 3.1 條紋類型與原因

| 特徵                                   | 最可能原因                       | 判斷方法                                       |
| -------------------------------------- | -------------------------------- | ---------------------------------------------- |
| 位置固定、細而直                       | 模唇刃口缺口或卡異物             | 10 倍放大鏡檢查刃口；插片後是否改善            |
| 多條、位置漂移                         | 濾芯破損、塗液含膠粒             | CL01-FL-02 壓差趨勢是否有驟降                  |
| 規則間距、寬而淡（肋狀紋）             | 塗布珠不穩定：間隙過大或黏度偏低 | 對照塗布間隙與黏度紀錄                         |
| 只在兩側邊緣                           | 墊片端部塗液乾涸                 | 停機時檢查墊片端部                             |

### 3.2 可調整參數（在各產品規格上下限內）

| 參數         | 調整範圍（相對目標值） | 對條紋的效果                                     |
| ------------ | ---------------------- | ------------------------------------------------ |
| 塗布間隙     | − 15 µm ～ + 10 µm      | 縮小間隙可穩定塗布珠，改善肋狀紋                 |
| 線速         | − 10 %                 | 降速可讓塗布珠更穩定；**必須同比例調整流量**，並確認 UV 光量 |
| 塗液黏度     | + 2 cP（請調配組調整）  | 黏度偏低時提高，改善肋狀紋                       |

> 降速會讓 UV 累積光量上升、烘箱停留時間增加，通常對品質無害；但**提高線速**會讓光量下降，處理條紋時不得提高線速。

### 3.3 歷史案例

2025-11-18 中班 HC-200 連續條紋 4 卷：二次過濾器濾芯破損，膠粒卡在模唇。當時現場持續插片清理，條紋反覆出現約 3 小時才停線。之後訂定「插片 2 次無效即停線」與「FL-02 壓差 1 小時內驟降 ≥ 0.05 MPa 視為濾芯破損」兩項規定。

## 4. CL-02（微凹版塗布）

### 4.1 條紋類型與原因

| 特徵                         | 最可能原因                   | 判斷方法                                       |
| ---------------------------- | ---------------------------- | ---------------------------------------------- |
| 細條紋、位置固定、間歇       | 刮刀刃口磨損或捲邊           | 刮刀累計公尺數；換下刮刀檢查刃口               |
| 寬而淡、塗液使用後期出現     | 網穴局部膠化堵塞             | 塗液加觸媒後時間；50 倍放大鏡檢查網穴          |
| 位置固定，換刮刀後仍存在     | 凹版輥表面刮傷               | 停機檢查輥面                                   |
| 全幅細密斜紋                 | 輥速比不當或刮刀壓力過低     | 對照設定值                                     |

### 4.2 可調整參數

| 參數       | 調整範圍            | 對條紋的效果                                  | 副作用                        |
| ---------- | ------------------- | --------------------------------------------- | ----------------------------- |
| 刮刀壓力   | ± 0.03 MPa           | 提高壓力可改善刮不乾淨造成的條紋              | 塗佈量下降、刮刀磨損加快      |
| 輥速比     | ± 0.1                | 調整轉移均勻性，改善斜紋                      | 塗佈量改變，需 XRF 確認       |
| 線速       | − 10 %              | 改善轉移穩定性                                | 烘箱停留時間增加（無害）      |

調整刮刀壓力或輥速比後，下一卷必須量測矽塗佈量（XRF）並確認快速篩檢結果，避免為了消除條紋而讓塗佈量或離型力偏離。

### 4.3 歷史案例

2026-03-15 夜班 RF-50 間歇條紋：刮刀刃口捲邊，更換刮刀後消除，未調整任何參數（詳見製造部異常處置紀錄 MFG-RPT-001）。CL-02 的條紋八成以上與刮刀有關，**不要一開始就調參數**。

## 5. 調整後確認

1. 調整後觀察至少 200 m（CL-01）或 500 m（CL-02）。
2. 每次調整記錄：時間、卷號與長度位置、調整前後數值、結果。
3. 條紋消除後，維持調整後的設定到該工單結束；下一工單回到產品規格目標值。
4. 同一個調整在 1 個月內使用 3 次以上，表示目標值可能不合適，PE 評估是否開立 ECN 修改規格。

## 6. 需要開 ECN 的情況

- 需要超出第 3.2、4.2 節範圍調整。
- 需要永久改變目標值。
- 更換墊片設計、凹版輥規格或刮刀規格。

依 PE-RULE-001 辦理。
